# FyAgent v0.4.9

This is the first published release since 0.4.5. It includes the changes
prepared as 0.4.6, 0.4.7 and 0.4.8, which were not published as separate
releases. The `v0.4.8` tag exists, but its release was stopped before
publication because its English release notes
(`docs/release-notes/v0.4.8-en.md`) were missing; 0.4.9 ships the same
product changes.

## Highlights

- **Session Center.** Export the final text of a session as a package, preview
  it on another device, check target compatibility, and keep local restore
  receipts. Native history export covers the reviewed Codex, OpenCode and
  Hermes formats; native restore is available for supported Codex, OpenCode,
  Hermes and Gemini versions.
- **Subscription reuse for OpenCode.** Extend the existing Claude Code, Codex
  and Grok Build support with OpenCode binding and restoration.
- **Clearer everyday actions.** Consolidated MCP and Skills actions, simpler
  installation and login presentation, and Chinese, English and Japanese
  manuals reorganized by feature.

## Fixes

- Hermes now compares against the official release's product version (for
  example 0.21.5) instead of the lagging PyPI package. If the lookup fails, the
  latest version is shown as unknown.
- OpenCode Desktop installs on macOS no longer fail version verification after
  the official download moved to OpenCode 2.x. Windows detection also
  recognizes the 2.x install folder.
- OpenCode CLI 2.x installations compare against the official `@opencode/cli`
  package; 1.x installations keep comparing against `opencode-ai`.
- When the official npm registry is unreachable and a mirror supplies the
  version, it is labelled as a mirror version rather than the official latest.
  Installation still uses the exact version and integrity checks.
- Claude Code installed with npm under a Homebrew prefix is recognized as an
  npm installation.
- Preserve per-app proxy retry, timeout and circuit settings; keep reply and
  tool-call boundaries; improve Grok native Responses compatibility; keep
  Health checks read-only; restore unchanged subscription bindings carried over
  from 0.4.5.

## Usage notes

FyAgent must remain running for local subscription forwarding. Model access and
quota depend on the account and upstream service. Session support depends on
the locally installed CLI version; unsupported formats stay unavailable.
Elevated Windows Session operations remain unavailable in this release.
