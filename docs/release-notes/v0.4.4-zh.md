# FyAgent v0.4.4

本版本新增集中式账号管理、Claude Code CLI 安装和可恢复的配置写入，统一生产前端，
并改进启动、导航、主题、滚动和弹窗交互。

## 主要更新

- **集中管理账号与软件连接。** 通过原生后端管理 OpenAI、xAI 登录会话，分别展示
  账号保存状态、软件连接状态和当前模型请求来源，不再将这些状态混为一谈。
- **明确配置影响与恢复方式。** 支持的账号连接操作先预览文件和备份位置；Codex、
  OpenCode Desktop 使用用途匹配的凭据，写入后回读校验，不能确认运行中软件已加载
  新凭据时明确提示等待重启。
- **安装 Claude Code CLI。** 复用官方 npm 包、已审核镜像和普通用户执行边界，
  安装或更新固定版本。Claude Code 仅适配 CLI，不会自动覆盖其他安装方式。
- **统一桌面体验。** 合并生产前端与检查流程，新增蓝色明暗主题、原生设置持久化
  和连续主题切换，改进内容就绪后显示主窗口、页面保活和自适应分配面板。
- **修复交互与平台问题。** 恢复正常滚动和被裁切的文字，修复弹窗返回来源与焦点，
  更正 WorkBuddy 识别和 Claude CLI 安装状态解析，修复 Windows OAuth 参数丢失及
  npm 批处理启动问题；Codex Desktop 未运行时不再提示不必要的重启。

## 升级与使用说明

登录只保存账号凭据，将账号连接到软件需要另行确认。Codex 官方账号连接可能注释
顶层 `model_provider` 选择项；断开连接时可恢复该选择项。切换已保存的第三方模型
来源保留 `auth.json` 和不属于该操作的配置。

备份和受保护恢复适用于已接入的文件写入流程，不等于多个文件之间具备原子事务。
失败操作仍可能需要重新读取状态或人工恢复，请独立备份重要配置。设置文件无法写入
时，主题切换保持可用，但下次启动不保证恢复最后一次选择。

安装完成不代表厂商登录或模型调用已验证。Windows 打开厂商安装向导后，仍需重新
扫描确认安装。Grok 原生凭据写入和 macOS `/Applications` 特权提交继续受现有
生产准入限制，不因安装包包含 helper 就自动开放。

## 安装包与验证材料

正式工作流完成原生构建、平台校验、所需签名与公证、产物证明后发布七个附件：

```text
FyAgent-0.4.4-macOS.dmg
FyAgent-0.4.4-Windows-x64-setup.exe
FyAgent-0.4.4-Windows-arm64-setup.exe
download-manifest.json
build-metadata.json
signing-status.json
artifact-attestation.sigstore.json
```

macOS 使用支持 Apple Silicon 与 Intel 的通用 DMG；Windows 分别提供 x64 和 ARM64
安装程序。Windows 是否具有 Authenticode 签名，以本次发布实际校验后的
`signing-status.json` 和 Release 自动附加的签名说明为准。
