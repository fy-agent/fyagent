# FyAgent v0.4.14

这是 0.4.12 之后的过渡预发布版，包含 #366 合入的后续修复和 #367 的原生上下文压缩修复。本次发布跳过 0.4.13，0.4.10 仍是最新正式版。

## 变化

- **Skills。** 一键更新前先确认要更新的技能列表。

## 修复

- **原生上下文压缩。** 保留压缩失败响应，不再把失败当成成功（#367）。
- **Windows 开机启动。** 查询启动状态时不再删除 Run 注册表项。
- **凭据。** 清理剩余的托管认证令牌副本，包括 Codex 回读时的副本。
- **批量分配。** 按目标集合比较回读结果，不再受键顺序影响；写入失败后不再执行结果会被丢弃的收敛读取。
- **提示词。** 报告明确的导入失败原因，允许托管提示词载荷带额外字段，并移除不可达的主目录报错。
- **OpenCode。** 使用统一的受检配置路径解析，路径解析失败时报错，不再触发 panic。
- **MCP 与模型。** 加强检查器对 PAT 和 contains 名称的脱敏；保留已配置的第三方 Codex 目录模型；Codex 预设列出全部五个 Moark 模型。
- **Grok 会话。** 将会话导入稳定等待与代理去重分开处理。

## 验证范围

发布准备会检查仓库契约，并要求 PR 与合并队列 CI 通过后才打标签。本版未做 Windows、macOS 真机人工验收。签名和公证结果需以发布流水线为准，这份说明本身不代表这些验证已通过。

## 使用说明

本地订阅转发需要 FyAgent 保持运行。从局域网访问代理需要访问密钥。模型访问权限与额度取决于账号和上游服务。
