# FyAgent v0.4.16

## Fixed

- Windows Codex installation no longer deletes a completed download because the signed-in user can modify `C:\` or ProgramData, because a bridge ACL differs from a recorded list, or because a file index changed. Copying still does not follow reparse points, and the copied bytes are still checked against the download.
- The PackageBridge directory left on 2026-10-30 is no longer used.
- Saving WorkBuddy configuration no longer fails when a parent directory's file index changes.
- QoderWork, TraeWork, WorkBuddy, and OpenCode desktop installers no longer require a stored signer company name. Windows still checks the package signature.
- OpenCode session data can be read when its storage directory is a symlink to another disk. Writes and deletes stay inside the resolved directory.

## Verification

Affected Rust tests and the release contract checks were run locally. Windows installers for this release are rebuilt; the sealed 0.4.15 packages are not reused. The macOS Applications install path stays closed.
