# FyAgent v0.4.16

## 修复

- Windows 上安装 Codex 时，不再因为当前用户可以修改 `C:\` 或 ProgramData、安装桥权限和记录不一致，或文件编号变化，就删掉已经下好的安装包。复制仍然不跟随重解析点，并核对拷贝内容与下载一致。
- 不再使用 2026-10-30 留下的旧 PackageBridge 目录。
- 保存 WorkBuddy 配置时，不再因为上级目录的文件编号变化而失败。
- 安装 QoderWork、TraeWork、WorkBuddy、OpenCode 桌面版时，不再要求签名者公司名与内置名单完全一致。Windows 仍检查安装包签名。
- 可以读取用符号链接指到其他磁盘的 OpenCode 会话数据。写入和删除仍留在解析后的数据目录内。

## 验证范围

本机跑了受影响的 Rust 与发布合同测试。Windows 安装包由本次发布运行重新构建，不复用 0.4.15 的离线密封包。Mac「应用程序」文件夹的安装通道没有打开。
