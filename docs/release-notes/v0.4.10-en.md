# FyAgent v0.4.10

A fix release after 0.4.9 focused on Windows installation and detection. The
issues were found during the v0.4.9 virtual machine installer smoke runs.

## Fixes

- **Claude Code and Grok Build status on the Windows directory page.** Both
  use the shared current-user helper. During parallel scans, a later request
  now waits in line for up to 30 seconds. Previously the request that lost the
  race showed "currently unavailable" and hid the install button.
- **When the helper cannot run.** If the helper stays busy past the wait,
  Explorer has no desktop view, or the launch request was never sent, the card
  shows "status unknown" instead of "currently unavailable", and one redacted
  reason line is written to the log.
- **Codex Desktop installation.** The index size of system folders such as
  `C:\ProgramData` can change during installation. This used to end in
  "installation not completed" (`PACKAGE_IDENTITY_MISMATCH`). Folders are now
  compared by volume serial number and file ID only. A folder that was actually
  replaced is still rejected, with a retry hint.
- **OpenCode Desktop on Windows ARM64.** One-click install is now offered. It
  uses the official ARM64 installer from the same version as the x64 stable
  build, and the UI shows that version.

## Verification scope

- Windows x64: Claude Code / Grok Build status and one-click install were
  checked on virtual machines, and Codex Desktop installed successfully in 4 of
  4 runs.
- Windows ARM64: the Codex Desktop and OpenCode Desktop installs could not be
  run end to end on GitHub's ARM virtual machine. Its Explorer has no desktop
  view, so any step that launches through Explorer fails there. What was
  confirmed: Codex passes the folder identity check, and OpenCode picks the
  versioned official ARM64 installer. These two installs, and Claude Code /
  Grok Build status on ARM64, still need a retest on a real ARM PC or a Wuying
  cloud desktop.

## Usage notes

FyAgent must remain running for local subscription forwarding. Model access and
quota depend on the account and upstream service.
