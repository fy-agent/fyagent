# FyAgent v0.4.12

This is a transitional pre-release after 0.4.11. It collects the high-priority fixes from the 0.4.11 review on top of the CC Switch 4.0.4 base. 0.4.10 remains the latest stable release.

## Additions and migration

- **Local network access needs an access key.** When the local proxy listens on anything other than loopback, requests must carry the access key. Keys are kept in memory, redacted in logs, health and usage output, and the active key survives a binary restore.

## Fixes

- **Proxy safety.** Decompression size is bounded, upstream error bodies are redacted in logs, health and usage, and the request body limit is enforced.
- **Credentials.** Oversized OpenCode credentials are rejected instead of silently dropping the access token, and tokens are zeroized before validation.
- **State and recovery.** A failed save restores the exact previous live file, stack read errors are reported, and own `__proto__` data is kept in the deep clone fallback.
- **Database and MCP errors.** Proxy column migration, MCP JSON conversion and OpenCode snapshot errors are propagated instead of ignored; failed MCP toggles roll back and JSON errors are redacted.
- **Provider import.** Shared snippet failures after manual import are reported, and raw post-processing errors are no longer shown.
- **Assignment and change plan.** The assignment keeps its failure stage, reason and recovery state, plain-text native errors are shown on their own line, and a plan retargeted to another provider is rejected without writing.
- **Prompts.** In-flight reads are cancelled before the post-write refresh, and the prompt view is reset per app (#363 #364).
- **CI and docs.** Toolchain versions are read from the declared contract; SECURITY.md and session manager docs are aligned.

## Verification scope

- Each of the nine fix branches passed a full CI run on the fork, and the combined branch passed a full CI run on the fork before release. No manual acceptance on real Windows or macOS machines and no signed installer.

## Usage notes

FyAgent must remain running for local subscription forwarding. If you reach FyAgent from another device on the local network, set the access key first.
