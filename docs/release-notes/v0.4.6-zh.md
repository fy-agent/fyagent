# FyAgent v0.4.6

相比 0.4.5，这次更新让客户项目更好整理、交付更容易交接，也让常用 AI 软件的配置更省心。

## 新增与升级

- **每个客户项目都有自己的工作区。** 可以分别记录项目目标、工作说明和要用的模型、提示词、技能及工具。不同项目分开管理，做完后可以归档，方便以后查找。
- **常见项目有了可参考的交付方案。** 内置经营周报、知识客服和经营查询入门包。可以先预览，再加入项目，也可以导出给其他人继续使用。经营周报附带本机示例，帮助你看懂需要哪些数据、结果是怎样算出来的。
- **检查结果和交接事项可以一起保存。** 哪些准备好了、哪些还没完成、谁确认过，都能记在项目里，并导出交接文档。项目资料发生变化后，旧检查会提示需要重新确认，减少拿旧结果当成新结果的情况。
- **OpenCode 也能使用已保存的订阅账号。** 在已有 Claude Code、Codex 和 Grok Build 支持的基础上，补齐 OpenCode 的订阅连接与配置恢复。可选择已保存的 ChatGPT 或 Grok 账号；软件配置被其他地方改动时，会先提示检查，避免覆盖你的修改。
- **常用操作更集中。** MCP 和技能管理的常用操作集中到工具栏，安装细节可以按需展开；账号登录提示更简明。中、英、日文手册按实际功能重新整理，查用法更直接。

## 修复与改进

- 修复从 0.4.5 升级后，原有订阅连接可能无法恢复或断开的问题；保留对后来修改过的配置的保护。
- 关闭本机转发、或由系统自动选择端口时，不再误改其他 AI 软件各自的重试和等待时间。
- 更新共用的模型来源时，保留各软件已有配置的信息和排序，避免独立设置被覆盖。
- 改善 AI 连续调用工具时的回复衔接，修正空推理内容干扰正常文字输出的问题；保留有效文字和缩进。
- 改善 Grok 的请求和工具调用兼容性，减少因参数格式不同导致的请求失败；调整数字格式时保留原值，避免大数字被改错。
- 修复部分配置没有成功分配，却显示成功的问题。
- 新建 MCP 工具时，不再默认分配给所有 AI 软件，减少误改其他软件配置。
- 改善 OpenCode 模型配置的读取、编辑和恢复，减少选错来源或覆盖外部修改的情况。
- 改善运行状态检查，减少对订阅连接的误报；检查只读取现有设置，不会改动配置。
- 修复清空搜索后的输入焦点、首次引导图标过大等界面问题。
- 加强升级时的数据保留、项目草稿与交付包版本保护，并修复 macOS 安装包公证处理顺序。

## 使用前了解两点

订阅复用需要 FyAgent 在后台运行；账号是否有相应模型和可用额度，取决于服务商。登录账号后，仍需选择要连接的软件。

客户项目的“生成项目说明文件”和“准备 Codex 独立工作目录”目前支持 macOS，Windows 暂不支持这两项操作。内置方案是项目起点，连接自己的知识库、数据库或客户系统仍需另行配置。
