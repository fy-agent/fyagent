# FyAgent v0.4.12

这是 0.4.11 之后的过渡预发布版，在 CC Switch 4.0.4 底座上收进 0.4.11 评审里的高优先级修复。0.4.10 仍是最新正式版。

## 行为变化：局域网访问需要访问密钥

- 本地代理只监听本机（127.0.0.1）时，用法和以前一样，不需要密钥。
- 本地代理监听局域网地址时，每个请求都必须带上访问密钥，没带或带错会被拒绝。以前局域网里的其他设备不带密钥也能直接用，升级后需要先在代理设置里设好密钥，再把它填到其他设备上。
- 访问密钥只保存在内存里，不写进日志、健康检查和用量记录，这些地方显示时都会打码。替换程序文件后，正在使用的密钥仍然有效。

## 修复

- **代理安全。** 解压大小有上限，上游错误内容在日志、健康检查和用量里打码，请求体大小限制生效。
- **凭据。** OpenCode 凭据过大时直接拒绝，不再悄悄丢掉访问令牌；校验前先清掉令牌内存。
- **状态与恢复。** 保存失败时恢复成原来的文件，读取失败会报出来，深拷贝保留自有的 `__proto__` 数据。
- **数据库与 MCP 报错。** 代理字段迁移、MCP JSON 转换和 OpenCode 快照的错误会如实报出；MCP 开关失败会回滚，JSON 报错打码。
- **手动导入供应商。** 导入后共享片段失败会提示，不再显示原始的后处理报错。
- **分配与变更计划。** 分配保留失败阶段、原因和恢复状态，原生纯文本报错单独一行显示；计划被改到别的供应商时拒绝且不写文件。
- **提示词。** 写入后刷新前先取消还在进行的读取，每个应用的提示词视图各自重置（#363 #364）。
- **CI 与文档。** 工具链版本从声明的合同读取；SECURITY.md 和会话管理文档已对齐。

## 验证范围

- 九条修复分支各自在分叉上跑完整检查通过，合成分支发版前也在分叉上跑完整检查通过。没有 Windows、macOS 真机人工验收，安装包没有签名。

## 使用说明

本地订阅转发需要 FyAgent 保持运行。从局域网其他设备访问时，请先设置访问密钥。
