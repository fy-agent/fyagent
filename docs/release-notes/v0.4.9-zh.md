# FyAgent v0.4.9

这是 0.4.5 之后的第一个正式发布版本，包含此前以 0.4.6、0.4.7、0.4.8 名义准备、但未单独发布的全部改动。`v0.4.8` 标签已存在，但因缺少英文发布说明（`docs/release-notes/v0.4.8-en.md`），其正式发布在发布前被流程拦下；0.4.9 与 0.4.8 的产品内容相同。

## 主要更新

- **会话中心**：可导出会话最终文本包、在另一台设备预览、检查目标兼容性，并保留本机恢复回执。原生历史导出支持已审阅的 Codex、OpenCode、Hermes 格式；受支持版本的 Codex、OpenCode、Hermes、Gemini 可原生恢复。
- **OpenCode 订阅复用**：在 Claude Code、Codex、Grok Build 之外，新增 OpenCode 的绑定与恢复。
- **日常操作更清晰**：合并 MCP 与 Skills 操作，简化安装与登录提示，中文、英文、日文手册按功能重新整理。

## 修复

- Hermes 最新版本改为对照官方发布的产品版本（例如 0.21.5），不再使用已滞后的 PyPI 包；查询失败时显示为未知。
- 官方下载切换到 OpenCode 2.x 后，macOS 上安装 OpenCode 桌面版不再因版本校验失败；Windows 也能识别 2.x 的安装目录。
- OpenCode 命令行 2.x 对照官方 `@opencode/cli` 包，1.x 继续对照 `opencode-ai`。
- 官方 npm 不可达、由镜像提供版本时，界面会标注为镜像版本，而不是官方最新；安装仍按精确版本和完整性校验执行。
- 通过 Homebrew 前缀下的 npm 安装的 Claude Code 会被正确识别为 npm 安装。
- 保留各应用的代理重试、超时与熔断设置；保持回复与工具调用边界；改进 Grok 原生 Responses 兼容性；健康检查保持只读；可恢复从 0.4.5 延续的未改动订阅绑定。

## 使用说明

本地订阅转发需要 FyAgent 保持运行。模型可用性和额度取决于账号与上游服务。会话功能取决于本机安装的命令行版本，不支持的格式保持不可用。提权 Windows 下的会话操作在本版本中仍不可用。

参见[变更记录](../../CHANGELOG.md)和[英文说明](v0.4.9-en.md)。
