# FyAgent v0.4.17

## Added

- **One-click multi-client model setup & live probing.** Configure mainstream models in one batch across WorkBuddy, Codex, Claude Code, OpenCode, Oh My Pi (`omp`), and Grok Build, verify connectivity inline against real endpoints, and surface Codex reload prompts globally (#431).
- **Model health overview, cross-app cloning, key rotation, and custom templates.** Inspect all six clients in one panel, clone working models across apps with automatic OpenAI/Anthropic URL adaptation, rotate API keys in place without wiping custom provider settings, and save reusable custom gateway templates (URL + model only, never storing API keys) (#433).
- **Portable workspace migration packs (`.fyagent-pack`, `<= 100 MiB`).** Export models, custom templates, MCP servers, global prompts, text-only skills, and lightweight session projections into a single Zstd-compressed, SHA-256-verified archive with optional PBKDF2-HMAC-SHA256 + AES-256-GCM passphrase encryption (payload-digest-bound AAD covering both model API keys and MCP env/header secrets; OAuth logins are never exported) (#434).
- **Agentless SSH remote config push.** Reuse `~/.ssh/config` and `ssh-agent` to push rendered client configs, MCP manifests, prompts, and text skills directly over SSH stdin with `umask 077`, symlink protection, automatic `~/.fyagent-remote-backups/` snapshots, and rollback on partial failure — no remote FyAgent installation required (#434).

## Changed

- **Streamlined UI copy.** Simplified repetitive guidance and status panels across primary pages while keeping initial bundle budgets verified (#431).

## Fixed

- **Codex auth & installer diagnostics.** Expanded local diagnostics for installer and subscription proxy paths while keeping authentication feedback compact (#377, #432).
- **Cross-client config robustness.** Prevented duplicate `fyagent-` prefixes in `omp`, preserved custom provider settings on Claude/Codex/Grok Build key rotation, bypassed system proxies for loopback probes, and ensured imported skills and MCP servers sync directly into fresh client directories (#433, #434).

## Verification

Full Rust `clippy -D warnings`, unit tests, repository contracts, Vitest suites, Playwright browser regressions, and isolated end-to-end integration tests (live loopback HTTP probing/cloning/rotation, old-PC to new-PC `.fyagent-pack` roundtrip with AAD tamper rejection, and live loopback OpenSSH `sshd` agentless push) passed locally and on CI. Windows 11 physical-machine verification for `#397` / `#377` remains tracked separately.
