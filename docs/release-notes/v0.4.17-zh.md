# FyAgent v0.4.17

## 新增

- **多客户端模型一键批量配置与实时测活。** 支持一次填写密钥并批量写入 WorkBuddy、Codex、Claude Code、OpenCode、Oh My Pi（`omp`）与 Grok Build，提供配置后内联测活与全局 Codex 重载提示（#431）。
- **全端模型健康总览、跨端克隆、密钥轮换与我的模板。** 在单一总览面板查看 6 端状态并并发测活；支持跨端克隆配置与主流网关 OpenAI/Anthropic 地址自动适配；支持按域名分组原地轮换 API Key（完整保留原有自定义 provider ID 与高级配置）；支持保存仅含地址与模型的「我的模板」（绝不落盘 API Key）（#433）。
- **轻量投影迁移包（`.fyagent-pack`，严格 `<= 100 MiB`）。** 采用投影策略打包模型、自定义模板、MCP、全局提示词、纯文本 Skills 与轻量会话投影（剥离工具原始日志、二进制附件与官方 OAuth 登录态），使用 Zstd 压缩与 SHA-256 校验，并支持个人口令 PBKDF2-HMAC-SHA256 + AES-256-GCM 加密（AAD 绑定正文摘要，同时加密模型 API Key 与 MCP 的 `env`/`headers` 凭证）（#434）。
- **SSH 远端免安装配置推送。** 直接复用本机 `~/.ssh/config` 与 `ssh-agent`，本地渲染就绪配置文件（Claude Code、Codex、OpenCode、`omp`、MCP、全局提示词与 Skills）并通过 SSH stdin 流式原子写入远端，全程 `umask 077`、防符号链接穿透、覆盖前自动备份至 `~/.fyagent-remote-backups/` 并在中途失败时自动回滚，远端主机无需安装 FyAgent（#434）。

## 优化

- **前端文案与界面精简。** 精简主页面冗余提示文案并收敛状态面板，保持首屏分包体积在预算内（#431）。

## 修复

- **Codex 安装与认证诊断增强。** 补齐本地安装器与订阅代理诊断信息，收紧认证结果区展示（#377、#432）。
- **跨端配置与导入鲁棒性。** 修复 `omp` 多重前缀与旧密钥残留、轮换时保留原有高级配置、环回测活绕过系统代理，以及新机导入迁移包后 Skills 与 MCP 自动落盘同步（#433、#434）。

## 验证范围

本地与 CI 已覆盖 Rust `clippy -D warnings`、单元测试、仓库契约、Vitest、Playwright 浏览器回归，以及三套隔离端到端集成测试（真实环回 HTTP 测活/克隆/轮换、旧机导出至新机还原含 AAD 篡改校验、真实环回 OpenSSH `sshd` 免安装推送与回滚）。`#397` / `#377` 的 Windows 11 实机安装验证继续单独跟踪。
