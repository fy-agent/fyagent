# FyAgent v0.4.10

这是 0.4.9 之后的修复版本，集中处理 Windows 上的安装和检测问题。这些问题是在 v0.4.9 的虚拟机安装冒烟中发现的。

## 修复

- **Windows 目录页的 Claude Code 和 Grok Build 状态**：两者共用当前用户 helper。并行扫描时，后到的请求现在会排队等待，最长 30 秒。以前抢输的一方会显示「当前不可用」，一键安装按钮也被隐藏。
- **helper 没能运行时的显示**：遇到以下情况，卡片显示「状态未知」，日志里写一行已去敏的原因，不再显示「当前不可用」：helper 一直忙到超时、资源管理器没有桌面视图、启动请求没有发出。
- **Codex Desktop 安装**：安装过程中 `C:\ProgramData` 等系统目录的索引大小会变化，以前这会导致「安装未完成」（`PACKAGE_IDENTITY_MISMATCH`）。现在目录只按卷序列号和文件 ID 比对。目录确实被替换时仍会拒绝安装，并提示重试。
- **Windows ARM64 上的 OpenCode Desktop**：现在提供一键安装。安装包是官方 ARM64 版本，版本号与 x64 稳定版一致，界面会显示这个版本号。

## 验证范围

- Windows x64：在虚拟机上验证了 Claude Code / Grok Build 的状态读取和一键安装，Codex Desktop 安装 4 次都成功。
- Windows ARM64：Codex Desktop 和 OpenCode Desktop 的安装在 GitHub 的 ARM 虚拟机上没能从头到尾走完。原因是这台虚拟机的资源管理器没有桌面视图，凡是要通过资源管理器启动的步骤都起不来。已经确认的部分：Codex 通过了目录身份检查；OpenCode 选中了带版本号的官方 ARM64 安装包。这两项以及 ARM64 上 Claude Code / Grok Build 的状态读取，需要在真实 ARM 电脑或无影云电脑上补测。

## 使用说明

本地订阅转发需要 FyAgent 保持运行。模型可用性和额度取决于账号与上游服务。
