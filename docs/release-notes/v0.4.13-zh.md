# FyAgent v0.4.13

这是一个过渡预发布版，在 CC Switch 4.0.4 底座上收进 0.4.10 之后的变化，并接续 0.4.12 的修复。0.4.10 仍是最新正式版。

## 行为变化：更新全部技能前确认清单

- 更新全部技能时，会先显示本次要更新的技能清单，确认后再开始更新。

## 修复

- **Windows 开机启动。** 查询开机启动状态只读取，不再删除 Windows 注册表 Run 键中的启动项。
- **凭据。** 托管认证流程中剩余的令牌副本会从内存中清零，包括回读 Codex 凭据时产生的副本。较短的凭据不再因为与公开的供应商名称、模型名称、本机地址或用量地址文字重合而导致误拒绝；未知扩展字段里残留凭据时仍会拒绝。
- **批量分配。** 回读按目标集合比较，不再因为对象字段顺序不同而误报不一致。写入失败后，去掉了结果被丢弃的额外收敛读取。
- **提示词。** 导入失败会给出明确原因。托管提示词允许携带额外的原生元数据，必填和可选字段仍会校验；路径解析中不会触发的主目录错误分支已移除。
- **OpenCode 配置。** 统一配置路径解析，模型读取、备份和写入复用同一个经过检查的路径。路径解析失败会在供应商操作、代理恢复和托管认证流程中报出，不再导致崩溃。
- **MCP 诊断。** 本地协议诊断提供 Inspector 配置，以及初始化和工具发现命令，不执行服务器命令，也不改变分配状态。复制的配置会遮住凭据，并加强了个人访问令牌及 URL 查询参数、片段、命令行参数和请求头中敏感名称的打码。实际诊断前，请仅在本机补入凭据。桌面端内容安全策略也已收紧。
- **Codex 模型。** 已配置的第三方目录模型保持可见，Moark 预设列出全部五个模型。
- **Grok 会话。** 会话导入的稳定等待窗口改为 60 秒，与代理去重窗口分开；代理去重仍为十分钟。
- **托盘刷新。** 模式保存后，托盘刷新失败会记录并重试一次，不会把已成功的保存报成失败。
- **CI 与文档。** 上游来源检查改用经过校验、固定版本的来源清单，不再依赖文档措辞，清单变化也纳入 CI 策略检查。文档检查已对齐，并补充回归测试。

## 验证范围

- 修复分支和合成发布分支已在分叉上跑完整 CI 检查。验证使用未签名测试包，不宣称已完成 Windows、macOS 真机人工验收。正式安装包通过发布流水线签名：macOS 安装包签名并公证，Windows 安装包签名。

## 使用说明

本地订阅转发需要 FyAgent 保持运行。从局域网其他设备访问时，请先设置访问密钥。
