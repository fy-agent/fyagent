# Release Notes

这个目录不再保留已发布版本的版本化说明。历史发布事实以仓库 Git 历史和已发布的
[GitHub Releases](https://github.com/fy-agent/fyagent/releases) 页面为准；当前文档不会为了适配现行产品边界而改写既有发布记录。

`vX.Y.Z-en.md`。如需提供中文或日文版本，可同时新增
`vX.Y.Z-zh.md` 或 `vX.Y.Z-ja.md`，并在本索引中添加链接。
