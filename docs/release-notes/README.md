# Release Notes

这个目录同时保存 FyAgent 的发布记录和项目继承的上游历史。版本号看起来属于两套体系，
原因如下：

| 范围 | 产品 | 怎样理解 |
|---|---|---|
| `v0.3.x` | FyAgent | FyAgent 独立版本线；从这里了解当前项目的变化 |
| `v3.6.0`–`v3.19.1` | CC Switch | 合入 FyAgent 之前的上游历史，保留原名称和原版本号 |

FyAgent v0.3.0 的源码基线包含 CC Switch v3.19.2。仓库没有虚构一份 v3.19.2 Release
Note；合入来源和边界记录在
[CC Switch v3.19.2 上游说明](../upstream/cc-switch-v3.19.2.md)。
