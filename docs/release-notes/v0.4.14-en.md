# FyAgent v0.4.14

This is a transitional pre-release after 0.4.12. It includes the follow-up fixes merged in #366 and the native compaction fix in #367. Version 0.4.13 was published separately as a pre-release; this release proceeds directly to 0.4.14. Version 0.4.10 remains the latest stable release.

## Changes

- **Skills.** Confirm the update-all list before updating skills.

## Fixes

- **macOS notarization.** Retry ticket stapling with backoff for transient failures (#371).
- **Native compaction.** Failed native context compaction responses are preserved as failures instead of being treated as successful (#367).
- **Windows auto-launch.** Reading auto-launch status no longer deletes the Run entry.
- **Credentials.** Zeroize remaining managed-auth token copies, including Codex readback copies.
- **Bulk assignment.** Compare readback by target set rather than key order, and skip the discarded convergence read after a failed write.
- **Prompts.** Report determinate import failure reasons and accept extra fields in managed prompt payloads; remove an unreachable home-directory error.
- **OpenCode.** Propagate configuration path resolution errors instead of panicking, using the shared checked path resolver.
- **MCP and models.** Harden inspector redaction for PAT and contains names, keep configured third-party Codex catalog models visible, and list all five Moark models in the Codex preset.
- **Grok sessions.** Separate session import settling from proxy deduplication.

## Verification scope

The release preparation verifies repository contracts and requires PR and merge-queue CI before tagging. No manual acceptance on real Windows or macOS machines has been performed for this release. Signing and notarization results must be checked in the release workflow; these notes alone do not establish those results.

## Usage notes

FyAgent must remain running for local subscription forwarding. Local network access to the proxy requires an access key. Model access and quota depend on the account and upstream service.
