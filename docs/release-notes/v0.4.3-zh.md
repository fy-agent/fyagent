# FyAgent v0.4.3

FyAgent v0.4.3 继续完善桌面端 Agent 控制平面。本版本重点收紧配置变更安全边界，
统一软件安装 / 更新的生命周期归属，并补齐 Windows 与 macOS 原生托管能力所需的
基础设施。

## 主要变化

- **更安全的配置变更。** 引入基于 SecretRef 的敏感信息边界与类型化 Change Plan，
  Provider 和 WorkBuddy 的修改可以在不向渲染层暴露敏感值的前提下完成校验、回滚
  与读回确认。
- **桌面端优先的 Agent 生命周期。** 支持的软件默认按桌面应用生命周期管理；由于
  Grok Build 没有桌面端，它仍是唯一保留 CLI 管理方式的 Agent。
- **Windows 托管能力继续收口。** 关闭式 Windows user helper 已覆盖正式的 Grok
  Build 安装 / 更新路径，同时 Agent inventory、readiness 与生命周期状态进一步由
  原生边界统一管理。
- **macOS privileged helper 基础设施。** 正式构建现在会打包用于已知
  `/Applications` 目标的嵌套 helper/client，并接入签名发布链路。需要强调的是，
  production system-scope commit 仍保持 fail-closed，只有专门的签名 / 公证 HIL
  验证通过后才能开放。
- **Codex 使用量同步日志更克制。** 预期内的 deferred 状态不再在正常运行中反复
  输出相同诊断信息。
- **跨平台开发诊断更清晰。** macOS 开发机可以显式运行 Windows MSVC cross check，
  用于发现 MSVC SDK / toolchain 缺失，同时不会把这些可选的跨平台前置条件变成普通
  bootstrap 的失败条件。

## 发布附件

正式 v0.4.3 工作流在原生构建、验证、需要时的签名 / 公证以及 attestation 全部通过
后，会发布且仅发布以下 7 个非空附件：

```text
FyAgent-0.4.3-macOS.dmg
FyAgent-0.4.3-Windows-x64-setup.exe
FyAgent-0.4.3-Windows-arm64-setup.exe
download-manifest.json
build-metadata.json
signing-status.json
artifact-attestation.sigstore.json
```

Windows 安装包分别在 x64 与 ARM64 原生 runner 上构建；macOS 发布 Universal DMG。
Release 工作流会在公开 GitHub Release 之前核对精确版本、源码提交、安装包清单、
平台元数据以及最终发布事务。

## 升级说明

- 升级时保留现有用户数据与配置。
- Agent 安装 / 更新是否可用，仍取决于具体产品、平台、检测到的安装状态以及对应的
  原生安全门禁。
- macOS privileged helper 被打包并不代表 `/Applications` 写入已对 production
  普遍开放；当前仍必须等待专门 HIL 证据满足既定门禁。

更完整的工程变更可查看 [`CHANGELOG.md`](../../CHANGELOG.md) 中的 `0.4.3` 章节。
