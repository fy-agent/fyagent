# FyAgent v0.4.15

这是准备中的说明，不是已发布的 GitHub Release。0.4.10 仍是 Latest，0.4.14 仍是预发布版。在 Windows `signing-status.json` 的 `mode` 仍是 `unsigned`、`signature.status` 仍是 `NotSigned` 时，不要把本说明对应的提交打成 `v0.4.15` 标签。当前正式流会把稳定标签发布为 Latest。

## 变化

- **首次安装。** 引导写明每一步会问什么、会装什么。材料里没有逐条记下的外部安装窗口仍标为待补证，不编成清单（#406）。
- **推荐安装。** 带 alpha、beta、preview、nightly、rc 的版本不进入推荐名单（#406）。
- **失效入口。** 说明 zen-gate 1.8.0 已去掉自己的免费车道；OpenCode 要在应用里输入 `/update`；qwen-code 从 0.25.1 起不再读取仓库上一级的 `QWEN.md` 和 `AGENTS.md`（#406）。
- **模型页。** 没有上次仍可见的目标时，冷启动打开 Claude Code。已有可见目标时保持原选择（#390）。
- **WorkBuddy。** 增加独立订阅绑定和内部对话路由；账号不可用时绑定失败关闭，不把流内失败当成正常结束（#375、#378）。

## 修复

- **账号与认证。** 把「账号已保存」「软件已连接」「需要重启」和「官方模型列表不可用」分开写。结果区不再把账号和连接操作挤到页面下方（#407）。
- **安装包准备失败。** 按下载、校验、解析、权限和磁盘等阶段留下可区分的诊断，不再把所有失败都说成磁盘或权限（#407）。日志仍在本机 `fyagent.log`，说明本身不含用户名或令牌。

## 签名

仓库里有 Certum／SimplySign adapter 和公开身份草稿（#405）。正式签名仍要仓库变量 `FYAGENT_WINDOWS_SIGNING_MODE=provider`，并且签名作业使用的 adapter 字节来自 Actions secret，而不是直接执行检出的脚本。本准备没有修改这个变量，也没有发布安装包。

## 验证范围

合并队列 CI 已覆盖 #405、#406、#407 合入后的前端、仓库合约、Windows/macOS 后端，以及 #407 的 Windows x64/arm64 native contracts。没有做安装、升级、卸载或启动。没有在干净的 Windows 上执行 `signtool verify /pa /all /v /tw`。macOS 安装包没有在本机用 `codesign` 或 `stapler` 复验。
