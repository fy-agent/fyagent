# 1.1 Introduction

## What FyAgent is

FyAgent is a local desktop configuration tool. It brings commonly used model, Skill, MCP, prompt, and memory settings for several AI applications into one interface and shows the affected settings before a write.

## What is in the interface

| Area | Purpose |
| --- | --- |
| AI software configuration | Scan local applications and, where supported, open installation, update, launch, authentication, and resource-assignment controls |
| Models | View or change model and Provider settings, with a preview before saving |
| Skills | Install, find, and assign Skills |
| MCP | Add, import, and assign MCP servers |
| Prompts | Edit prompt files for supported applications |
| Memory | Edit long-term memory for OpenClaw and Hermes, plus OpenClaw daily memory files |

## Supported applications

AI software configuration, Models, Skills, and MCP primarily cover these seven applications:

- QoderWork CN
- TRAE Work CN
- WorkBuddy
- Grok Build
- Codex
- Claude Code
- OpenCode

Prompt management also covers Gemini, OpenClaw, and Hermes. The Memory area is for OpenClaw and Hermes.

The available controls differ by application. For example, FyAgent can install or inspect authentication for some applications, while others only provide a link to the official flow. Use the controls shown on the current page as the supported boundary.

## Data and writes

Working data is stored in `~/.fyagent` by default. When FyAgent needs to change another application's configuration, it first shows the affected settings. See [Configuration files](../6-faq/6.1-config-files.md) for exact paths and backup guidance.

FyAgent is under active development. Back up important configuration before an upgrade and read the release notes for the version you install.

## Supported platforms

- Windows 10 or later
- macOS 12 (Monterey) or later
