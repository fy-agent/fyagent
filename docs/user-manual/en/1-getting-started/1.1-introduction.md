# 1.1 Introduction

## What is FyAgent

FyAgent is a cross-platform desktop control center for people who use AI Workers, AI Agents, and assistants. It brings model choices, tool connections, Skills, working instructions, configuration, and usage records into one local app while managing supported tools such as **Claude Code**, **Claude Desktop**, **Codex**, **Gemini CLI**, **OpenCode**, **OpenClaw**, and **Hermes**.

You do not need to begin with terms such as Provider, MCP, or Prompt. To the person using the product, they are an AI's source of intelligence, its tool connections, and its way of working. FyAgent makes choices that were scattered across files and tools visible, editable, and easier to carry forward.

## Vision and Current Boundary

FyAgent aims to become a portable digital persona for everyone in the AI era—and the steering wheel that keeps people in charge. As AI becomes more capable, where its models come from, what it connects to, what it can do, and how it acts should remain visible and chosen by the person using it.

Long-term memory and a complete persona that persists across tools remain part of the product direction. The current release focuses on unified management of models, tool connections, Skills, working instructions, configuration, routing, and usage records. A capability is presented as current only after it has been implemented and verified.

## What Problems Does It Solve

When you use several AI tools, you may encounter these problems:

- **Tedious multi-provider switching**: Using different API providers (official, proxy services) requires manually editing configuration files
- **Scattered configurations**: Claude Code, Claude Desktop, Codex, Gemini, OpenCode, OpenClaw, and Hermes each have independent configuration files in different formats
- **No usage monitoring**: No visibility into how many API calls were made or how much they cost
- **Service instability**: When a single provider goes down, your entire workflow is interrupted

FyAgent brings these scattered choices back into one desktop interface.

## Core Features

### AI Brain: Models and Providers
- One-click switching between multiple API provider configurations
- Preset templates for quickly adding common providers
- Universal provider feature for sharing configurations across apps
- Claude Desktop third-party providers, direct mode, and model mapping
- Usage query and balance display
- Endpoint speed testing

### Tool Connections, Skills, and Working Instructions
- **Tool connections (MCP)**: Manage the services and tools your AI can reach
- **Working instructions (Prompts)**: Reuse instructions and switch them by scenario
- **AI skills (Skills)**: Install and manage reusable capability extensions

### Routing, Recovery, and Usage Records
- Local proxy service for request logging and usage statistics
- Automatic failover that switches to a backup provider when the primary one fails
- Circuit breaker mechanism to prevent repeated retries against failing providers
- Detailed token usage tracking and cost estimation

## Technical Architecture

FyAgent is built with a modern technology stack:

- **Frontend**: React 18 + TypeScript + Tailwind CSS
- **Backend**: Tauri 2 + Rust
- **Data Storage**: SQLite (providers, MCP, Prompts) + JSON (device settings)

This architecture ensures:
- Consistent cross-platform experience
- Native-level performance
- Secure local data storage
