# 2.2 Update tools and diagnose installation conflicts

When an update appears to succeed but the old version still runs, the usual cause is another installation earlier on PATH. FyAgent checks for this before and after updates. In Settings, only **Grok Build** can be updated.

## Update Grok Build

- Use the action on the Grok Build card to update it.
- Other CLI cards are read-only and do not show update actions.
- Claude Desktop, Codex Desktop, and OpenCode Desktop updates belong on the Agent page, not the Settings CLI list.

Before an update, FyAgent checks known installation sources. If it finds several Grok Build copies, it shows their sources and versions and asks you to confirm. The interface does not show local absolute paths.

## Diagnose tools

Diagnosis checks Claude Code, Codex CLI, Gemini CLI, Grok Build, OpenCode, OpenClaw, and Hermes. It reads sources and versions; it does not remove old files for you.

When there is a conflict, first determine which copy your everyday terminal resolves. Do not choose a copy only because it looks newer, and do not manually delete an unfamiliar system directory.

## Read the result

| Result | Meaning | Next step |
|---|---|---|
| Success | The action completed and the refreshed version matches the expected state | Run `--version` once in your working terminal |
| Hard failure | The install or update itself did not complete | Check the network, permissions, and current-user environment |
| Version unchanged | The action finished but the old version still resolves | Review multiple installation sources |
| Installed but not runnable | Files may exist, but the version command cannot start | Check the runtime, shell, and PATH |

After an update, FyAgent silently diagnoses that tool again. A clean result removes an old conflict message; remaining duplicates keep their source list visible.

## A practical troubleshooting order

1. Run the tool diagnostic in FyAgent.
2. In the terminal where you write code, run the tool's `--version`.
3. Compare that result with the sources shown by FyAgent.
4. Remove an unwanted copy through the official channel that installed it, then reopen the terminal.
5. Refresh the version in FyAgent and make one real test call.
