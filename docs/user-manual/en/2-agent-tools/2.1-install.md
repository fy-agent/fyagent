# 2.1 Install Agent tools and check their versions

FyAgent can show which Agent tools are available on your machine and install most of them. Open **Settings → About → Tool management**.

## Supported tools

Version detection covers Claude Code, Codex CLI, Gemini CLI, Grok Build, OpenCode, OpenClaw, and Hermes. Each card shows the current version, an available newer version, and whether the tool was found in Windows or macOS.

FyAgent can install or update Claude Code, Gemini CLI, Grok Build, OpenCode, OpenClaw, and Hermes. The Codex CLI card is read-only: it detects versions but does not offer install or update actions. Install Codex CLI through its official distribution path.

## Install one tool

1. Open Tool management and wait for version detection to finish.
2. Select **Install** on a tool that is not available.
3. Wait for the command to finish. FyAgent checks the version again instead of treating a zero exit code as enough proof.
4. If the version is still missing, review the diagnostic result for another installation or a path that the selected shell cannot reach.

Only one install or update group runs at a time, which prevents several global package managers from changing the environment concurrently.

## Copy all install commands

**Copy install commands** places a platform-specific command set on the clipboard so you can inspect and run it in your own terminal. Windows and macOS receive different commands. The list contains the six managed tools and deliberately excludes Codex CLI.

Treat the copied text as commands to review, not blanket permission to run them. Check the download hosts, package manager, and terminal privileges first.

## Verify the result

A useful installation result has two parts: the card shows a version, and the tool starts in the terminal where you actually work. A successful installer followed by an empty version usually means that files were written but PATH, the Node.js runtime, or the shell prevents the executable from starting. Continue with [updates and installation conflict diagnostics](./2.2-update-diagnose.md).
