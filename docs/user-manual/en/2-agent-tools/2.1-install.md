# 2.1 Install Agent tools and check their versions

FyAgent can show which CLI tools are on your machine and can install or update **Grok Build**. Open **Settings → About → Local environment check**. Manage Claude Desktop, Codex Desktop, and OpenCode Desktop from the Agent page instead of pasting CLI commands here.

## Supported tools

Version detection covers Claude Code, Codex CLI, Gemini CLI, Grok Build, OpenCode, OpenClaw, and Hermes. Each card shows the current version and any newer version that can be detected.

Only **Grok Build** can be installed or updated from Settings. The other CLI cards are read-only. For desktop apps, use the matching product on the Agent page.

## Install Grok Build

1. Open Local environment check and wait for version detection to finish.
2. Select **Install** on the Grok Build card. This installs the official xAI npm package (downloaded through mainland npm mirrors).
3. To use the official CLI installer instead, choose **Install with official CLI**. FyAgent does not switch an existing install automatically.
4. Wait for the action to finish. FyAgent checks the version again instead of treating a finished installer as enough proof.
5. If the version is still missing, review the diagnostic result for conflicting installation sources.

A successful install only means the Grok Build CLI is on this computer. Sign-in and online inference still depend on whether xAI services are reachable on your network.

Only one Grok Build install or update group runs at a time.

## Verify the result

A useful result has two parts: the card shows a version, and `grok` starts in the terminal where you actually work. If the version stays empty, continue with [updates and installation conflict diagnostics](./2.2-update-diagnose.md).
