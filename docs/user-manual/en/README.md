# FyAgent user manual

FyAgent manages AI software installation, accounts, models, Skills, MCP, prompts and memory on Windows and macOS. The desktop interface is in Simplified Chinese; this guide preserves its labels so you can find each action.

## Quick start

1. [Install and launch FyAgent](installation.md).
2. Scan in 「AI软件配置」 and select a target. Use 「安装前检查／更新前检查」, review the final confirmation and explicitly start before completing any required login.
3. Open 「模型管理」, select the same target, enter or select a model configuration, test it and confirm saving.
4. Check the model in the target software, then assign Skills or MCP, or enable a prompt as needed.
5. Review account and connection status in 「账号与认证」; manage installation and login in 「AI软件配置」 and model configuration in 「模型管理」. Use 「记忆模块」 for OpenClaw and Hermes memory.
