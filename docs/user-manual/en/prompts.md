# Prompt management

Choose an application in 「提示词管理」. Each application has its own library, searchable by name, description, content or ID.

1. Click 「新建提示词」, enter a name, description and content, then 「保存」. 「从文件导入」 imports the selected application's current prompt file.
2. Browse 「FDE 预设」 and click 「使用此预设」 to create a draft. Edit and save it.
3. Select a saved prompt and enable it for the target application. Each application uses one enabled prompt at a time.
4. Expand 「当前使用的内容」 to inspect the file content, then check the effect in the target application.

New, imported and preset-based entries are saved to the library and require a separate enable action. Saving an enabled entry updates the active content. Disabling the last enabled prompt clears its current prompt file; retain any content you need beforehand.

Disable a prompt before deleting it. Switching applications, selecting another entry or leaving with unsaved edits opens a discard confirmation; return and save to keep your draft.

If a write completes but refreshing fails, reload the current content before deciding whether another write is needed.
