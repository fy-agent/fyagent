# Accounts and authentication

「账号与认证」 contains 「账号」 (Accounts) and 「软件连接」 (Software connections).

## Add an official account

1. Click 「添加账号」 and choose an available account type, such as ChatGPT, Grok or GitHub Copilot.
2. Choose 「仅保存账号」 (Save account only) or an offered connection purpose, then browser or device-code login.
3. Check the displayed official domain and complete the official page. Use only the device code generated by your current FyAgent login attempt.
4. Return to inspect the result. Use 「继续登录」 or refresh account status when needed.

You can set a default account or sign in again. After saving an account, select software and an account under 「软件连接」. Review the authentication files, model source and backup locations before confirming a connection or switch. Restart the target software when instructed.

## Choose the model source

Inspect Codex's current model source in its software connection. Connecting an account and choosing the request's model source are separate steps: preview and confirm the source switch, then inspect its result. See [models](models.md) for subscription setup.

Read the disconnect confirmation. Restoring Codex's third-party source restores use of the top-level `model_provider`; the account remains saved. Removing an account deletes FyAgent's saved credentials and connection records; using it again requires login. Check the actual file effects in the operation dialog.

If status cannot be read, refresh first. If official login finished but remains unconfirmed, inspect the target software before continuing.
