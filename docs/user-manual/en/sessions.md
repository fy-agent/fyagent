# Sessions

## Browse and export

Choose a software and session, then read the original or Q&A preview. An unsupported source extractor may still allow original-text viewing; restoring an existing package depends on the target version's verified writer capability. 「导出迁移包」 previews selected sessions before choosing an output file.

## Import and restore

1. Use 「导入会话包」 to select and read a migration package.
2. Select snapshots, target software and an absolute local workspace directory; review conflict choices. An unverified/unsupported target writer cannot restore.
3. Review the preview and use 「确认恢复至目标软件」. Wait for this operation; closing a dialog does not cancel an already started write.
4. Inspect the receipt and target readback, then open the session in the target app, check after restart and send a new message.

## Four separate facts

| Displayed fact | Meaning                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------ |
| 「包导入」     | Package validated with a matching receipt                                                  |
| 「目标写入」   | System-confirmed target storage write; failure/unknown needs review                        |
| 「目标读回」   | System-verified local target history                                                       |
| 「实机闭环」   | Receipt separately records verification of opening, restart, next request and actual reply |

Readback does not mean a model replied. 「标记：我已手动续聊」 saves your report only; it does not advance system stages or replace readback/native evidence.

Use 「重试同一恢复」 only when every selected session has a complete, matching failed result for the same restore and the interface allows retry. If results are missing, incomplete, still pending or unknown, use 「核对恢复回执」 and inspect the target first; do not start a duplicate restore. Refresh failed reads and retain the package and target files while results remain unknown. A clickable button or user report is not restore success.
