# 会话中心

## 浏览和导出

选择软件和会话，查看原文或问答预览。源版本不能提取时，可用原文仍可查看；可否导入已有包取决于目标版本的写入能力，不能仅凭源提取能力判断。「导出迁移包」先预览选中的会话，再选择输出文件。

## 导入和恢复

1. 点击「导入会话包」，选取迁移包并读取。
2. 选择会话快照、目标软件及本机工作区绝对目录，阅读冲突处理选项。目标写入未验证或不受支持时不能恢复。
3. 核对预览后「确认恢复至目标软件」。写入期间等待同一次操作；关闭窗口不等于取消已经开始的写入。
4. 查看恢复回执与目标读回结果，再在目标软件打开会话、重启检查并发送一条新消息。

## 分清四个事实

| 页面事实 | 表示什么                                                   |
| -------- | ---------------------------------------------------------- |
| 包导入   | 包已核验并建立匹配回执                                     |
| 目标写入 | 系统确认写入目标存储；失败或未知仍需核对                   |
| 目标读回 | 系统核验目标本地历史                                       |
| 实机闭环 | 按系统回执分别说明打开、重启、下一轮请求与真实回复是否验证 |

读回通过不等于真实模型已回复。「标记：我已手动续聊」只保存你的说明，不升级系统阶段，也不替代读回或实机证据。

只有全部所选会话都已核对到同一次恢复的完整失败结果，且界面允许时，才使用「重试同一恢复」。结果缺失、不完整、仍在处理中或未知时，先「核对恢复回执」并检查目标，勿另起重复恢复。读取失败先刷新，状态仍未知时保留迁移包和现有目标文件；不把按钮可点或自报当成恢复成功。
