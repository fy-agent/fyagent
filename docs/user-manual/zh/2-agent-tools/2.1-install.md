# 2.1 安装 Agent 工具并查看版本

FyAgent 可以帮你看清本机装了哪些 CLI 工具，并安装或更新 **Grok Build**。入口在“设置 → 关于 → 本地环境检查”。Claude Desktop、Codex Desktop、OpenCode Desktop 请到 Agent 页面安装，不要用设置页里的 CLI 命令。

## 支持范围

版本探测覆盖 Claude Code、Codex CLI、Gemini CLI、Grok Build、OpenCode、OpenClaw 和 Hermes。卡片会显示当前版本和可用的新版本。

其中只有 **Grok Build** 可以从设置页安装或升级。其余 CLI 卡片只读。需要桌面应用时，使用 Agent 页面里对应产品的安装入口。

## 安装 Grok Build

1. 打开“本地环境检查”，等待版本探测结束。
2. 在 Grok Build 卡片上点击“安装”。默认会安装 xAI 官方 npm 包（通过国内 npm 镜像下载）。
3. 如需官方命令行安装器，再点“使用官方命令行安装”。已有安装不会被自动改到另一种方式。
4. 等待操作完成。FyAgent 随后会重新读取版本，而不是只看安装过程是否结束。
5. 如果仍然看不到版本，打开同一卡片的诊断结果，确认安装来源是否冲突。

安装成功只表示本机有了 Grok Build CLI。登录和在线推理是否可用，仍取决于 xAI 服务在你网络中是否可达。

同一时间只会执行一组 Grok Build 安装或升级，避免并发改写同一安装。

## 安装完成后怎么确认

可靠结果需要同时满足：卡片能显示版本，并且你在实际工作的终端里能运行 `grok`。版本仍为空时，继续看[升级与安装冲突诊断](./2.2-update-diagnose.md)。
