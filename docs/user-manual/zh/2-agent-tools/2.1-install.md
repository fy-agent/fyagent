# 2.1 安装 Agent 工具并查看版本

FyAgent 可以帮你看清本机装了哪些 Agent 工具，也能安装其中大部分工具。入口在“设置 → 关于 → 工具管理”。

## 支持范围

版本探测覆盖 Claude Code、Codex CLI、Gemini CLI、Grok Build、OpenCode、OpenClaw 和 Hermes。FyAgent 会显示当前版本、可用的新版本以及工具所在的 Windows、WSL、macOS 或 Linux 环境。

其中 Claude Code、Gemini CLI、Grok Build、OpenCode、OpenClaw 和 Hermes 可以从这里安装或升级。Codex CLI 卡片只负责检查版本，不提供安装和升级按钮；需要安装 Codex CLI 时，请使用它自己的官方安装方式。

## 安装一个工具

1. 打开“工具管理”，等待版本探测结束。
2. 在未安装的工具卡片上点击“安装”。
3. 等待命令执行完毕。FyAgent 随后会重新读取版本，而不是只看安装命令是否返回成功。
4. 如果仍然看不到版本，打开同一卡片的诊断结果，检查是否装在了另一个环境或当前终端找不到的位置。

同一时间只会执行一组安装或升级操作，避免多个全局包管理命令同时改写环境。

## 一次复制全部安装命令

“复制安装命令”会按当前系统生成一组命令，便于你在自己的终端里检查后执行。Windows 和类 Unix 系统使用不同命令；这组命令只包含六个可管理工具，不包含 Codex CLI。

复制出来的命令不是无条件授权。执行前仍应确认下载地址、所用包管理器和终端权限，尤其不要把来历不明的命令直接交给管理员终端。

## Windows 与 WSL

如果工具实际装在 WSL 中，可以为该工具选择 `sh`、`bash`、`zsh`、`fish` 或 `dash`，并选择 `-lic`、`-lc` 或 `-c` 启动参数。修改后 FyAgent 会用新设置重新探测版本。

选择应与平时能正常运行该工具的 WSL 终端一致。若不确定，先在自己的 WSL 终端执行工具的 `--version`，再按相同 shell 配置 FyAgent。

## 安装完成后怎么确认

一个可靠的结果应同时满足两点：卡片能显示版本，并且你在实际工作的终端里能运行该工具。命令退出成功但版本仍为空，通常表示工具虽然写入了磁盘，却因 PATH、Node.js 版本或 shell 环境而无法启动。遇到这种情况，请继续看[升级与安装冲突诊断](./2.2-update-diagnose.md)。
