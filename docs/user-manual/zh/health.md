# 运行状态

在侧栏打开「运行状态」，选择软件，点击「重新检查此软件」；需要查看整体情况时点击「检查全部软件」。可按软件名称搜索或筛选状态。

检查按「安装与启动」「账号与配置」「连接与使用」展示结果。先处理标出的失败或待确认项目，再使用结果中提供的入口前往安装、账号或模型配置页。

「停止检查」会等待当前检查完成，再停止后续软件。个别读取失败时，可以单独重试；页面保留上次结果时，注意其检查时间。

本机检查不测试远端服务或额度。结果超过 5 分钟后应重新检查；要验证模型能否返回响应，前往 [模型管理](models.md) 使用「测试连通」。修改安装、认证或模型配置后，再回来检查目标软件。
