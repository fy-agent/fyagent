# 提示词管理

在「提示词管理」选择应用。每个应用有自己的提示词库；可搜索名称、描述、内容或 ID。

1. 点击「新建提示词」，填写名称、描述和内容，然后「保存」。也可用「从文件导入」读取所选应用当前提示词文件。
2. 在「FDE 预设」浏览领域内容，点击「使用此预设」生成草稿，按需要修改后保存。
3. 选中已保存的提示词并启用，让目标应用使用它。每个应用同时使用一条已启用提示词。
4. 展开「当前使用的内容」检查实际文件内容，再到目标应用确认效果。

新建、导入或从预设保存的提示词先进入库中，需要另行启用。编辑已启用条目并保存会更新正在使用的内容。停用最后一条提示词会清空对应的当前提示词文件；修改前保留需要的内容。

已启用的提示词需先停用再删除。编辑未保存时，切换应用、选择其他条目或离开页面会提示放弃更改；要保留草稿，返回并保存。

若提示写入后刷新失败，重新加载当前内容再判断结果，避免反复覆盖。
