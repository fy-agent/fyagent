# 模型管理

打开「模型管理」，先在「选择应用」中选定目标。各软件提供对应的配置方式；TRAE Work CN 的第三方模型在该软件内添加，再回 FyAgent 查看当前模型。

## 填写与保存

1. 填写配置名称（如有）、服务地址、API Key 和模型 ID。服务地址使用 HTTP(S)，密钥只填写在 API Key 字段。
2. 点击「拉取模型」选择服务返回的模型，或手动填写模型 ID。WorkBuddy 和 OpenCode 可添加多个 ID；先检查待保存列表。
3. 点击「测试连通」，选定模型后「开始测试」。测试会发送请求，可能产生少量用量。
4. 使用「保存并设为当前配置」或「保存并应用」，阅读文件变更与备份说明，再确认保存。
5. 检查当前配置是否更新，并按提示在目标软件刷新、重新打开或新建会话。

Claude Code 的服务地址通常应去掉末尾 `/v1`，以免追加成重复路径；按服务商文档确认。需要本地免鉴权服务时，使用页面提供的「不使用 API Key」。Codex 的 WebSocket 传输、内置生图扩展按服务兼容性选择。

覆盖同名模型、删除已有模型前确认目标。出现配置已变化或保存后待确认提示时，重新读取当前设置再操作。

## 使用账号订阅

在「使用账号订阅（实验性）」选择已保存的 ChatGPT 或 Grok 账号，查看模型选项或填写支持的模型 ID。Grok 示例选项的实际可用性以服务响应为准。

Codex 点击「保存 Codex 订阅配置」后，继续到「账号与认证」预览并确认来源切换。其他目标按界面「应用到」按钮确认文件更改。使用订阅时保持 FyAgent 在后台运行；完全退出会停止本机转发。调用是否可用以及额度使用以服务返回为准。

账号准备见 [账号与认证](accounts.md)，失败排查见 [问题处理](troubleshooting.md)。
