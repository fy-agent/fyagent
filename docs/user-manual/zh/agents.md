# AI 软件配置

进入侧栏「AI软件配置」，点击「开始扫描」或「重新扫描」，查看本机软件与安装状态。选择软件的「进行配置」打开详情；「查看状态」进入该软件的运行检查。

## 安装、更新和打开

1. 在目录或「安装与更新」中使用当前软件显示的安装、更新按钮。
2. 出现安装目标选择时，选择要安装或更新的位置，检查确认内容后继续。发现多个安装时，先选定目标。
3. 等待操作完成，再检查安装状态与版本。Windows 厂商安装向导打开后，先完成向导再刷新。
4. 已安装的软件可通过「打开软件」启动。

Grok Build 的安装按钮使用官方 npm 包，也可选择「使用官方命令行安装」或切换安装方式。登录和在线服务取决于网络。切换方式时按确认窗口继续，等待安装结果更新。

## 为软件配置能力

在详情中选择模型、Skills、MCP 或提示词，查看当前内容，并通过对应「管理」入口编辑。Skills 和 MCP 的开关用于在该软件中启停项目；提示词选择条目后可启用。

认证区域按软件提供「登录」「连接 Provider」或账号管理入口。完成官方登录后返回并「刷新状态」。停止等待后，已经打开的官方登录窗口仍可能继续处理。

若扫描或安装结果无法读取，先重新扫描；安装位置变化时重新选择目标。配置步骤见 [模型](models.md)、[账号](accounts.md)、[Skills](skills.md)、[MCP](mcp.md) 和 [提示词](prompts.md)。
