# 1.1 软件介绍

## FyAgent 是什么

FyAgent 是一款本地桌面配置工具。它把多款 AI 软件常用的模型、Skills、MCP、提示词和记忆文件放到一个界面中管理，并在写入前展示将要修改的内容。

## 界面里有哪些内容

| 区域 | 用途 |
| --- | --- |
| AI 软件配置 | 扫描本机软件，并在支持时提供安装、更新、启动、认证和资源分配入口 |
| 模型管理 | 查看或修改模型与 Provider 设置，保存前预览变更 |
| Skills 管理 | 安装、查找和分配 Skills |
| MCP 管理 | 添加、导入和分配 MCP 服务 |
| 提示词管理 | 编辑支持软件的提示词文件 |
| 记忆模块 | 编辑 OpenClaw 与 Hermes 的长期记忆，以及 OpenClaw 的每日记忆 |

## 支持范围

AI 软件配置、模型、Skills 和 MCP 以以下七款软件为主：

- QoderWork CN
- TRAE Work CN
- WorkBuddy
- Grok Build
- Codex
- Claude Code
- OpenCode

提示词管理还支持 Gemini、OpenClaw 和 Hermes。记忆模块用于 OpenClaw 与 Hermes。

不同软件开放的能力不同。例如，有的软件可以由 FyAgent 安装或检查认证状态，有的软件只能打开官方入口。以页面当前显示的操作为准。

## 数据与写入

工作数据默认保存在本机 `~/.fyagent`。需要修改其他软件的配置时，FyAgent 会先显示变更范围；具体路径和备份方法见[配置文件说明](../6-faq/6.1-config-files.md)。

FyAgent 仍在开发中。升级前请备份重要配置，并阅读对应版本的发布说明。

## 支持的平台

- Windows 10 及以上
- macOS 12（Monterey）及以上
