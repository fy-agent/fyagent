# 1.1 软件介绍

## 什么是 FyAgent

FyAgent 是面向 AI Worker、AI Agent 和智能助手使用者的跨平台桌面控制中心。它把模型选择、工具连接、Skills、行为指令、配置和使用记录集中到一个本地应用里，并统一管理 **Claude Code**、**Claude Desktop**、**Codex**、**Gemini CLI**、**OpenCode**、**OpenClaw** 和 **Hermes** 等受管应用。

你不需要先弄懂 Provider、MCP 或 Prompt 这些术语。对使用者来说，它们分别是 AI 的大脑来源、工具连接和工作方式。FyAgent 让原本散落在不同文件和工具里的选择变得看得见、改得动，也更容易继续使用。

## 愿景与当前边界

FyAgent 希望成为 AI 时代每个人的随身数字人格，也是人掌握 AI 的方向盘：让 AI 越来越强的同时，模型从哪里来、连接了什么、会做什么、怎样行动，仍然由人看得见并作决定。

长期记忆和跨工具延续的完整数字人格仍是产品继续建设的方向。当前版本先解决模型、工具连接、Skills、行为指令、配置、路由和使用记录的统一管理；只有真正实现并经过验证的能力，才会列入现有功能。

## 解决什么问题

在同时使用多个 AI 工具时，你可能会遇到这些问题：

- **多供应商切换麻烦**：使用不同的 API 供应商（官方、中转服务商），需要手动修改配置文件
- **配置分散难管理**：Claude Code、Claude Desktop、Codex、Gemini、OpenCode、OpenClaw、Hermes 各有独立的配置文件，格式不同
- **无法监控用量**：不知道 API 调用了多少次，花了多少钱
- **服务不稳定**：单一供应商出问题时，整个工作流中断

FyAgent 用一个桌面界面把这些分散的选择收回来。

## 核心功能

### AI 大脑：模型与供应商
- 一键切换多个 API 供应商配置
- 支持预设模板，快速添加常用供应商
- 统一供应商功能，跨应用共享配置
- Claude Desktop 第三方供应商、直连模式与模型映射
- 用量查询与余额显示
- 端点速度测试

### 工具连接、技能与行为指令
- **工具连接（MCP）**：管理 AI 可以连接的服务和工具
- **行为指令（Prompts）**：管理可复用的工作指令，按场景切换
- **AI 技能（Skills）**：安装和管理可复用的能力扩展

### 调度、恢复与使用记录
- 本地代理服务，记录请求日志和用量统计
- 自动故障转移，主供应商失败时自动切换备用
- 熔断器机制，防止频繁重试失败的供应商
- 详细的 Token 用量追踪与成本估算

## 支持的应用

| 应用 | 说明 |

| **Claude Desktop** | Claude 桌面应用，支持官方登录与第三方 3P profile |

## 支持的平台

- **Windows** 10 及以上
- **macOS** 12 (Monterey) 及以上

## 技术架构

FyAgent 使用现代化的技术栈构建：

- **前端**：React 18 + TypeScript + Tailwind CSS
- **后端**：Tauri 2 + Rust
- **数据存储**：SQLite（供应商、MCP、Prompts）+ JSON（设备设置）

这种架构确保了：
- 跨平台一致的体验
- 原生级别的性能
- 安全的本地数据存储
