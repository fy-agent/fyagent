# MCP 管理

## 添加服务

打开「MCP 管理」，点击「添加 MCP」，填写唯一 ID、名称及可选描述、标签。

「快速配置」按传输类型填写：

- `stdio`：启动命令、每行一个参数、可选工作目录和环境变量（`KEY=VALUE`）。
- HTTP / SSE：连接地址及所需请求头（`Name: Value` 或 `Name=Value`）。

也可在「JSON 编辑」填写单个服务配置。保存前检查目标软件分配；已有服务通过详情中的「编辑」修改。

## 从目录或现有配置导入

「发现」中可搜索精选 MCP，打开文档检查用途、认证和运行环境要求，选择目标并填写业务参数后安装。需要 Node.js / npx 或 uv / uvx 时，先安装相应运行环境。

「导入现有」读取已有软件中的 MCP 配置，完成后在「已安装」检查导入数量与内容。

## 分配和维护

选择服务，在分配区启用或停用目标软件，随后在目标软件刷新 MCP 列表并尝试调用。配置成功保存后，还需检查运行环境、凭据和远端服务是否可用。

「重新配置」会覆盖现有配置，确认前检查手动修改；「删除」会从管理列表和已启用的软件中删除该服务。环境变量与请求头可能包含密钥，分享排错材料时先脱敏。
