# Skills 管理

## 安装或导入

在「发现」搜索 Skill，阅读说明，选择目标并确认安装；到「已安装」检查结果。「更多 → 从 ZIP 安装」先选文件，再确认目标。

「更多 → 导入本地 Skill」扫描未管理项目：选择需要的条目，调整软件开关，点击「预览导入」，核对名单和目标后「确认导入」。原来源目录保留；链接来源可读取并复制到普通目录。

## 分配和失败恢复

单项在分配区切换目标开关。「批量分配」先筛选并勾选资源，选择一个目标及启用/停用，预览后确认；完成以保存后回读为准。来源或分配已变化时重新预览。失败可能已发生部分写入，先刷新实际结果，再选择未完成项重新预览。

导入结果显示「已入库」时，到「已安装」处理目标分配，不重复导入；无法确认是否入库时，用「刷新并查看已安装」先检查。只有仍未管理且结果已确认的未完成项才重新选择并预览重试。

详情提示链接来源和只读目标。链接目录（包括父目录链接）不修改、不删除；只读目标的开关不可操作，普通目标仍可分配。更新或卸载遇到链接保护时，保留原目录，改用普通目录后再操作。FyAgent 读回不证明外部软件已加载，仍需在目标软件重新加载并检查。

## 更新、备份和存储

「检查更新」后可更新单项或「更新全部」；批量更新可能部分成功，检查数量并只处理失败项。卸载前阅读确认；备份不是每次都保证存在。「更多 → 备份恢复」只恢复列表中实际存在的备份，先选目标再「恢复」。

「更多 → Skill 设置」选择自动、符号链接或复制。存储迁移需确认；链接保护拒绝时迁移未执行，普通 I/O 错误可能逐项部分完成，按结果检查后再操作。默认库为 `~/.fyagent/skills/`，统一库为 `~/.agents/skills/`；卸载备份在 `~/.fyagent/skill-backups/`。
