# Skills 管理

## 安装与导入

在「Skills 管理 → 发现」搜索名称或用途，查看说明，选择安装目标并确认安装。回到「已安装」查看详情和分配状态。

「更多」提供两种导入方式：

- 「导入本地 Skill」：扫描已安装应用中的未管理 Skills，选择项目与要启用的软件，点击「导入所选」。
- 「从 ZIP 安装」：选择 ZIP，核对目标与显示的安装目录后确认。

## 分配与更新

选中已安装 Skill，在分配区按软件切换开关。修改会影响目标软件的 Skill 目录；操作完成后检查开关结果，并在目标软件重新加载。

点击「检查更新」，可以更新单个 Skill 或「更新全部」。批量操作完成后检查成功与失败数量，只重试失败项目。

## 备份和存储

卸载会从管理列表和启用的软件中移除 Skill。需要恢复时打开「更多 → 备份恢复」，选择恢复目标和已有备份，点击「恢复」。删除备份前确认它不再需要。

「更多 → Skill 设置」可选择自动、符号链接或复制同步方式，并保存。存储迁移按钮用于迁移到 FyAgent 或统一目录；阅读确认内容，迁移期间保持应用运行，结束后检查失败项。

FyAgent 默认 Skill 目录为 `~/.fyagent/skills/`，卸载备份位于 `~/.fyagent/skill-backups/`；实际安装位置以详情显示为准。
