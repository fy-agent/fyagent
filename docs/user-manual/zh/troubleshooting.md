# 问题处理与配置位置

| 情况                       | 下一步                                                                                    |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| 软件未发现或安装状态待确认 | 在「AI软件配置」重新扫描；完成安装向导后刷新，发现多个安装时重新选定目标。                |
| 登录后仍显示待确认         | 完成官方页面步骤，再刷新账号或软件认证状态。                                              |
| 模型无法调用               | 核对服务地址、API Key、模型 ID 和网络，在「模型管理」测试连通；检查目标软件当前模型来源。 |
| 配置已保存但未生效         | 重新读取当前配置，按提示重启目标软件或新建会话。                                          |
| 配置被其他操作修改         | 刷新后检查当前内容，再重新确认；先保留仍需使用的草稿。                                    |
| Skill / MCP 已分配但不可用 | 检查目标软件开关、目录、运行环境和凭据，在目标软件重新加载。                              |
| 页面显示上次结果           | 使用重试或刷新；先确认当前内容再重复写入。                                                |

## 默认文件位置

`~` 表示当前用户主目录。软件自定义目录或环境变量可能改变实际位置，优先查看操作窗口与软件自身配置。

| 内容                     | 默认位置                                                           |
| ------------------------ | ------------------------------------------------------------------ |
| FyAgent 数据库与设备设置 | `~/.fyagent/fyagent.db`、`~/.fyagent/settings.json`                |
| FyAgent Skills 与备份    | `~/.fyagent/skills/`、`~/.fyagent/skill-backups/`                  |
| Claude Code 配置与提示词 | `~/.claude/settings.json`、`~/.claude/CLAUDE.md`                   |
| Claude MCP               | `~/.claude.json`                                                   |
| Codex 认证、配置与提示词 | `~/.codex/auth.json`、`~/.codex/config.toml`、`~/.codex/AGENTS.md` |
| Gemini 提示词            | `~/.gemini/GEMINI.md`                                              |
| OpenCode 配置与提示词    | `~/.config/opencode/opencode.json`、`~/.config/opencode/AGENTS.md` |
| OpenClaw 工作区          | `~/.openclaw/workspace/`                                           |
| Hermes 长期记忆          | `~/.hermes/memories/MEMORY.md`、`~/.hermes/memories/USER.md`       |

直接编辑前备份相关文件，避免与 FyAgent 同时写入；编辑后重新读取页面。环境变量中的认证或地址与软件配置不一致时，先核对目标软件的实际来源，保留所需值后再调整。

需要报告问题时，附上系统、FyAgent 版本、软件名称、操作步骤和脱敏后的错误信息，参见 [支持说明](../../../SUPPORT.md)。API Key、令牌、认证文件内容不要放入截图或公开问题。
