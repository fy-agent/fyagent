# 账号与认证

「账号与认证」包含「账号」与「软件连接」两个视图。

## 添加官方账号

1. 点击「添加账号」，选择当前可用的账号类型，例如 ChatGPT、Grok 或 GitHub Copilot。
2. 选择「仅保存账号」或界面提供的连接用途，再选择浏览器登录或设备码登录。
3. 核对显示的官方域名，继续并完成官方页面操作。设备码只使用本次由 FyAgent 生成的代码。
4. 返回 FyAgent 查看结果；需要时使用「继续登录」或刷新账号状态。

账号可设为默认或重新登录。保存账号后，在「软件连接」选择软件和账号，检查将修改的认证文件、模型来源及备份位置，再确认连接或切换。按结果提示重新启动目标软件。

## 选择模型来源

在 Codex 软件连接中检查当前模型来源。连接官方账号与选择请求使用的模型来源是两个步骤：按界面预览并确认来源切换，再检查结果。订阅模型的配置步骤见 [模型管理](models.md)。

断开前阅读确认窗口：Codex 恢复第三方来源时会恢复顶层 `model_provider` 的使用；账号仍保存在账号列表。移除账号会删除 FyAgent 保存的凭证及连接记录，重新使用需再次登录。实际文件影响以操作窗口列出的内容为准。

认证状态读取失败时，先刷新；官方登录已完成但状态待确认时，检查目标软件后再继续。
