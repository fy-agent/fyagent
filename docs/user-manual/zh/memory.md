# 记忆模块

打开侧栏「记忆模块」，选择「长期记忆」或「每日记忆」。

## 长期记忆

选择 OpenClaw 或 Hermes 的 `MEMORY.md` / `USER.md`，编辑正文并「保存」。显示「尚未创建」的文件会在保存时创建。

OpenClaw 的文件位于其工作区；可点击「打开 OpenClaw 工作区」查看目录。Hermes 的长期文件位于 `memories/`，页面提供启用开关和字符上限。超出上限时可继续保存，但部分内容可能无法被 Hermes 使用，建议先精简。

## 每日记忆

每日记录来自 OpenClaw 工作区的 `memory/YYYY-MM-DD.md`。

- 点击「创建或打开今天」，编辑并保存；保存后创建文件。
- 搜索每日记录，选择结果查看和修改正文。
- 「打开记忆目录」可在文件管理器中查看目录。
- 删除前核对日期与确认窗口；确认后该本机文件会被删除。

有未保存更改时，切换文件、记忆类型或离开页面会要求确认。需要保留内容时先保存。刷新失败时页面可能仍显示上次内容，重试读取后再继续编辑。
