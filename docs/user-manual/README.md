The short guides follow the eight sidebar entries: AI software, accounts, models, Skills, MCP, prompts, sessions and memory. They include next steps for partial or unconfirmed operations. Installation is covered separately in each language.

The runtime Health page and legacy WebDAV/S3 cloud sync have retired. Account, connection and request-source information is in 「账号与认证」; model request tests are in 「模型管理」. Existing legacy sync files are left untouched and unused.

This revision follows current interface labels and code paths. No new native screenshots were captured. Older screenshots, where retained in other guides, are not evidence of the current interface or a completed operation.
