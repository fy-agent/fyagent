# 1.1 ソフトウェア紹介

## FyAgent とは

FyAgent は、ローカルで動作するデスクトップ設定ツールです。複数の AI アプリで使うモデル、Skills、MCP、プロンプト、メモリーの設定をひとつの画面にまとめ、書き込み前に変更対象を表示します。

## 画面の構成

| 画面 | 用途 |
| --- | --- |
| AI ソフトウェア設定 | ローカルのアプリをスキャンし、対応している場合はインストール、更新、起動、認証、リソース割り当てを行う |
| モデル管理 | モデルと Provider 設定を確認・変更し、保存前に変更内容を表示する |
| Skills 管理 | Skills をインストール、検索、割り当てする |
| MCP 管理 | MCP サーバーを追加、インポート、割り当てする |
| プロンプト管理 | 対応アプリのプロンプトファイルを編集する |
| メモリーモジュール | OpenClaw と Hermes の長期メモリー、および OpenClaw のデイリーメモリーを編集する |

## 対応範囲

AI ソフトウェア設定、モデル、Skills、MCP は、主に次の 7 アプリを対象とします。

- QoderWork CN
- TRAE Work CN
- WorkBuddy
- Grok Build
- Codex
- Claude Code
- OpenCode

プロンプト管理は Gemini、OpenClaw、Hermes にも対応します。メモリーモジュールは OpenClaw と Hermes を対象とします。

利用できる操作はアプリごとに異なります。FyAgent からインストールや認証状態の確認ができるアプリもあれば、公式の手順を開くだけのアプリもあります。現在の画面に表示される操作を対応範囲として確認してください。

## データと書き込み

作業データは既定で `~/.fyagent` に保存されます。他のアプリの設定を変更する場合は、先に変更対象を表示します。正確なパスとバックアップ方法は[設定ファイル](../6-faq/6.1-config-files.md)を参照してください。

FyAgent は開発中です。更新前に重要な設定をバックアップし、インストールするバージョンのリリースノートを確認してください。

## 対応プラットフォーム

- Windows 10 以降
- macOS 12（Monterey）以降
