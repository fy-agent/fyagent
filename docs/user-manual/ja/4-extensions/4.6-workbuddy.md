# 4.6 WorkBuddy のモデル設定

WorkBuddy は、上部のアプリ切り替えで Codex の次にある独立した入口です。この画面が読み書きするのは現在のユーザーの `~/.workbuddy/models.json` だけで、Provider、MCP、Skills の設定には混ぜません。

## 接続してモデルを取得する

1. WorkBuddy に切り替えます。
2. Base URL を入力します。FyAgent がモデル一覧のエンドポイントを組み立てるため、通常はサービスの基点までで十分です。
3. API Key を入力します。目のボタンは表示を切り替えるだけで、ディスク上の既存 Key を読み戻しません。
4. サービスが匿名アクセスを明示的に許す場合だけ「API Key なしを許可」を有効にします。
5. 「モデルを取得」を実行します。

Base URL はホストを持つ絶対 HTTP(S) URL で、ユーザー情報、クエリ、フラグメントを含められません。リモートの平文 HTTP には警告が出ます。FyAgent は同一オリジンのリダイレクトだけを許可し、別サイトへ API Key を送りません。

## 選択して保存する

取得後は検索、個別選択、現在の検索結果の全選択・解除ができます。有効な応答が長すぎて一部だけ表示された場合、次の完全な取得が成功するまで警告が残ります。遠端一覧にないモデル ID は 1 行ずつ手入力できます。

保存時は、関係のないモデル、並び順、未知のフィールドをできるだけ保ったまま `models.json` を更新します。既存モデルの ID は表示しますが、保存済み API Key を画面へ戻すことはありません。

対象 ID がすでに存在すると、重複 ID を示して再確認を求めます。この確認は保留中の同じ保存だけに有効で、使い回せません。確認前に別プロセスがファイルを変更した場合は、外部変更を上書きせず、保存を止めて状態を更新します。

## Key とバックアップ

API Key は現在のコンポーネントメモリ、1 回の Tauri リクエスト、保護された設定ファイルにだけ存在します。WorkBuddy 画面を離れるとメモリ上の Key は消去されます。保存時は同じディレクトリの `models.json.backup` を保ち、主ファイルとバックアップを安全に置き換えます。

新しい Key を入力せず既存モデルを更新する場合、古い Key を消す選択肢が表示されることがあります。対象モデルを確認してから有効にしてください。

## エラーの分類

| 分類 | 表示される可能性があるコード | 確認すること |
|---|---|---|
| URL・認証 | `WORKBUDDY_INVALID_URL`、`WORKBUDDY_API_KEY_REQUIRED` | Base URL の構造と匿名アクセスの可否 |
| ネットワーク・応答 | `WORKBUDDY_FETCH_HTTP_ERROR`、`WORKBUDDY_FETCH_TIMEOUT`、`WORKBUDDY_FETCH_REDIRECT_REJECTED`、`WORKBUDDY_FETCH_RESPONSE_TOO_LARGE`、`WORKBUDDY_FETCH_INVALID_SCHEMA` | サービス状態、同一オリジンの転送、`/models` の応答形式 |
| 設定の読み取り | `WORKBUDDY_CONFIG_READ_FAILED`、`WORKBUDDY_CONFIG_INVALID_JSON`、`WORKBUDDY_CONFIG_ROOT_NOT_ARRAY`、`WORKBUDDY_CONFIG_ROOT_UNSUPPORTED`、`WORKBUDDY_CONFIG_MODELS_NOT_ARRAY`、`WORKBUDDY_CONFIG_INVALID_ENTRY` | ファイルを退避し、JSON 構造を確認。FyAgent は壊れたデータを自動修復しません |
| 対象モデル | `WORKBUDDY_CONFIG_NO_TARGET_MODELS`、`WORKBUDDY_CONFIG_DUPLICATE_TARGET`、`WORKBUDDY_CONFIG_EXISTING_TARGET` | 1 件以上選び、重複または既存 ID を処理 |
| 同時変更・確認 | `WORKBUDDY_CONFIG_CONCURRENT_MODIFICATION`、`WORKBUDDY_OVERWRITE_TOKEN_INVALID`、`WORKBUDDY_OVERWRITE_TOKEN_EXPIRED` | 状態を更新し、選択を見直して保存し直す |
| 書き込み・内部 | `WORKBUDDY_CONFIG_BACKUP_FAILED`、`WORKBUDDY_CONFIG_WRITE_FAILED`、`WORKBUDDY_INTERNAL_ERROR` | 元ファイルを残したまま、権限と空き容量を確認 |

エラーには対処に必要な状態だけを含め、API Key、完全な応答、上書き確認の情報は表示しません。
