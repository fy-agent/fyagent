# プロンプト管理

「提示词管理」でアプリを選びます。アプリごとにライブラリがあり、名前、説明、内容、ID で検索できます。

1. 「新建提示词」で名前、説明、本文を入力して「保存」します。「从文件导入」は選択アプリの現在のプロンプトファイルを取り込みます。
2. 「FDE 预设」を閲覧し、「使用此预设」で下書きを作ります。必要な編集を加えて保存します。
3. 保存したプロンプトを選び、有効化します。各アプリで同時に使用するプロンプトは 1 件です。
4. 「当前使用的内容」を開いてファイル内容を確認し、対象アプリで効果を確認します。

新規、取り込み、プリセットから保存した項目はライブラリに入り、別途有効化します。有効な項目を編集して保存すると、使用中の内容も更新されます。最後の有効項目を無効化すると現在のプロンプトファイルが空になるため、必要な内容を先に保存しておいてください。

削除前にプロンプトを無効化します。未保存の編集がある状態でアプリ、項目、ページを切り替えると破棄の確認が出ます。残したい下書きは戻って保存してください。

書き込み後の再取得に失敗した場合は、現在の内容を再読み込みしてから、再度書き込む必要があるか判断します。
