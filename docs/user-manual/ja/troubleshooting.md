# 問題への対処と設定ファイル

| 状況                                             | 次の操作                                                                                     |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| ソフトウェアが見つからない・インストールが未確認 | 「AI软件配置」で再スキャンします。ウィザードを完了して更新し、対象のインストールを選びます。 |
| ログインが未確認                                 | 公式ページで操作を完了し、アカウントまたはソフトウェアの認証状態を更新します。               |
| モデルを呼び出せない                             | URL、API Key、モデル ID、ネットワーク、現在のモデル接続先を確認し、「测试连通」を使います。  |
| 保存した設定が反映されない                       | 現在の設定を再取得し、案内に従って対象を再起動するか、新しいセッションを開始します。         |
| 他の操作で設定が変更された                       | 必要な下書きを保存し、現在の内容を再取得してから確定し直します。                             |
| 割り当てた Skill / MCP が使えない                | スイッチ、保存先、実行環境、認証情報を確認し、対象ソフトウェアで再読み込みします。           |
| 前回の結果が表示される                           | 再試行・更新し、現在の内容を確認してから再度書き込みます。                                   |

## 既定の場所

`~` はユーザーのホームディレクトリです。カスタム設定や環境変数で場所が変わる場合は、操作画面と対象ソフトウェアの設定を優先してください。

| 内容                           | 既定パス                                                           |
| ------------------------------ | ------------------------------------------------------------------ |
| FyAgent データベースと端末設定 | `~/.fyagent/fyagent.db`、`~/.fyagent/settings.json`                |
| FyAgent Skills とバックアップ  | `~/.fyagent/skills/`、`~/.fyagent/skill-backups/`                  |
| Claude Code 設定とプロンプト   | `~/.claude/settings.json`、`~/.claude/CLAUDE.md`                   |
| Claude MCP                     | `~/.claude.json`                                                   |
| Codex 認証、設定、プロンプト   | `~/.codex/auth.json`、`~/.codex/config.toml`、`~/.codex/AGENTS.md` |
| Gemini プロンプト              | `~/.gemini/GEMINI.md`                                              |
| OpenCode 設定とプロンプト      | `~/.config/opencode/opencode.json`、`~/.config/opencode/AGENTS.md` |
| OpenClaw ワークスペース        | `~/.openclaw/workspace/`                                           |
| Hermes 長期メモリ              | `~/.hermes/memories/MEMORY.md`、`~/.hermes/memories/USER.md`       |

直接編集する前にバックアップを取り、FyAgent との同時書き込みを避けます。編集後は画面を再読み込みしてください。環境変数と認証・接続先設定が食い違う場合は、対象ソフトウェアが使う設定元を確認し、必要な値を保管して調整します。

問い合わせには OS、FyAgent のバージョン、ソフトウェア名、手順、秘密情報を伏せたエラーを添え、[サポート](../../../SUPPORT.md) の案内に従ってください。API Key、トークン、認証ファイルの内容はスクリーンショットや公開 Issue に載せないでください。
