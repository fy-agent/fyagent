# インストールと更新

[fy-agent/fyagent Releases](https://github.com/fy-agent/fyagent/releases) から OS とアーキテクチャに合うパッケージを取得し、その Release の署名情報、SHA-256、ソース SHA、attestation を確認します。

| OS      | 要件                                 | パッケージ                                                                           |
| ------- | ------------------------------------ | ------------------------------------------------------------------------------------ |
| Windows | Windows 10 以降、x64 / ARM64         | `FyAgent-X.Y.Z-Windows-x64-setup.exe` または `FyAgent-X.Y.Z-Windows-arm64-setup.exe` |
| macOS   | macOS 12 以降、Intel / Apple Silicon | `FyAgent-X.Y.Z-macOS.dmg`                                                            |

Windows ではインストーラーを実行し、ウィザードを完了します。インストールはマシン全体が対象です。信頼に関する警告が出た場合は、配布元とそのビルドの署名状態を確認し、組織のセキュリティ方針に従ってください。インストーラーがブロックされた場合は[以下](#windows-でインストーラーがブロックされた場合)を参照してください。

macOS では DMG を開き、`FyAgent.app` を「アプリケーション」にドラッグして起動します。ブロックされた場合は取得元と検証情報を確認し、「システム設定 → プライバシーとセキュリティ」で「このまま開く」の案内に従います。Gatekeeper とダウンロード隔離保護は有効にしておきます。

初回起動時は用途を選ぶか、「跳过引导」（ガイドをスキップ）で一覧を開きます。対象ソフトウェアの検出とインストールは [AI ソフトウェア設定](agents.md) を参照してください。MCP が Node.js / npx や uv / uvx を必要とする場合は、表示される実行環境を先に準備します。

FyAgent の更新は同じ Releases ページから対応パッケージを取得し、各 Release の説明に従います。アンインストールは Windows の「設定 → アプリ」、macOS ではアプリをゴミ箱へ移動します。個人データの既定保存先は `~/.fyagent/` です。ファイルを整理する前に必要なデータをバックアップしてください。

## Windows でインストーラーがブロックされた場合

現在の Windows インストーラー（`FyAgent-X.Y.Z-Windows-x64-setup.exe` および `FyAgent-X.Y.Z-Windows-arm64-setup.exe`）はマシン全体を対象とする NSIS インストーラーです（インストール時にユーザー アカウント制御（UAC）の管理者昇格プロンプトが表示されます）。現在、Windows 版インストーラーには Authenticode 署名が含まれておらず、GitHub Releases ページの「Windows installer signing status」表では `NotSigned` と表記されています。

システムやセキュリティ対策ソフトによってブロックされた場合は、セキュリティ保護を安易に無効化せず、「まず検証し、確認後に許可する」原則に従ってください：

1. **まず検証（ファイルハッシュとビルド証明）**：許可や実行を行う前に、必ずファイルの配布元と整合性を確認してください。
   - 公式の [GitHub Releases](https://github.com/fy-agent/fyagent/releases) ページからのみインストーラーをダウンロードします。
   - PowerShell を開き、インストーラーがあるディレクトリで次のコマンドを実行して SHA-256 ハッシュを計算します（X.Y.Z を実際のバージョン番号に置き換え、ARM64 版は対応するファイル名に置き換えてください）：
     ```powershell
     Get-FileHash .\FyAgent-X.Y.Z-Windows-x64-setup.exe -Algorithm SHA256
     ```
     出力されたハッシュ値が、対応する Release ページの表に記載されている SHA-256 と完全に一致することを確認します。ハッシュ値が一致しない場合はファイルが破損しているか改ざんされている可能性があるため、直ちに削除し、絶対に実行しないでください。
   - GitHub CLI がインストールされている場合は、Release に添付されているビルド証明（attestation）で真正性を検証することもできます：
     ```powershell
     gh attestation verify .\FyAgent-X.Y.Z-Windows-x64-setup.exe --repo fy-agent/fyagent
     ```
2. **Microsoft Defender SmartScreen で「Windows によって PC が保護されました」と表示される場合**：
   - 署名のないインストーラーを実行した際に SmartScreen の警告が表示された場合は、「詳細情報」をクリックします。
   - 表示されたアプリ名とファイル名が、ダウンロードしたインストーラーと一致していることを確認します。
   - 「実行」をクリックし、その後に表示されるユーザー アカウント制御（UAC）のプロンプトで管理者権限を許可すれば、インストールを続行できます。
3. **ファイルがインターネット取得としてマークされている場合（ブロックの解除）**：
   - ブラウザーからダウンロードしたファイルには Web のゾーン識別子が付与されることがあります。インストーラーをダブルクリックしても反応がない場合やブロックされる場合は、ファイルを右クリックして「プロパティ」を選択します。
   - 「全般」タブ下部の「セキュリティ」項目を確認します。
   - 「許可する」にチェックを入れて「OK」をクリックしてから、再度インストーラーを実行します（※「許可する」のチェックボックスが表示されている場合のみ必要な操作です）。
4. **スマート アプリ コントロール（Windows 11）によって直接ブロックされる場合**：
   - Windows 11 でスマート アプリ コントロールが有効になっている場合、まずクラウド サービスによってアプリの安全性が判定され、安全と判定されたアプリは実行できます。安全性を確認できず、有効な署名もない場合にブロックされます。ブロックされた場合、「実行」ボタンは表示されず、個別のファイルのみをホワイトリストに追加したり許可したりすることはできません。
   - 個人の端末で実行するには、「Windows セキュリティ → アプリとブラウザー コントロール → スマート アプリ コントロールの設定」で無効化するしかありません。
   - **注意**：スマート アプリ コントロールを無効化するとシステム全体の保護レベルが低下するため、慎重に判断してください。近年の Windows 更新プログラムにより、Windows のリセットや再インストールを行わずに再度有効化できるようになりました。旧バージョンや当該更新をまだ受け取っていない端末では依然としてリセットや再インストールが必要な場合がありますので、端末の設定および Microsoft の説明をご確認ください。システムのセキュリティを低下させたくない場合は、将来の署名付きリリースをお待ちください。企業の管理端末などの場合は、組織の IT ポリシーに従い、システム管理者に相談してください。
5. **ウイルス対策ソフトや Defender による誤検知・隔離**：
   - セキュリティ対策ソフトによってインストーラーが脅威と誤認されてブロックまたは隔離された場合は、まず手順 1 に従って SHA-256 ハッシュ値を確認し、ファイルが改ざんされていないことを確かめてください。
   - インストールのためにウイルス対策ソフトやリアルタイム保護全体を無効化することは避けてください。
   - ハッシュ値の一致を確認できたら、当該インストーラーファイルのみを対象とする最小限の除外設定を行うか、隔離から復元してください。
   - 検出精度の改善のため、セキュリティベンダーへ誤検知のサンプルを送信することもできます（Microsoft Defender の誤検知申請窓口：[Microsoft Security Intelligence ファイル送信](https://www.microsoft.com/wdsi/filesubmission)）。
   - また、[Q&A ディスカッション](https://github.com/fy-agent/fyagent/discussions/categories/q-a) に状況を報告することもできます。

## FyAgent から AI ソフトウェアをインストールする

「AI软件配置」で「安装前检查」（インストール前の確認）または「更新前检查」（更新前の確認）を選びます。複数の場所がある場合は対象を選び、ソフトウェア、バージョン、OS とアーキテクチャ、取得元、今回の書き込み内容を確認します。対象選択には場所の選択があり、次の説明は事前確認と明示的な開始を担当するため、役割が異なります。

ソフトウェアの公式資料とダウンロード元を照合します。ドメインや URL の表示だけでパッケージの検証が完了したことにはなりません。実行時にも選択した取得元、パッケージの識別情報、対象を検証します。CLI 操作では確認済みパッケージまたは既存 CLI の更新方式を使い、説明画面から任意のパッケージ名、URL、パスを渡しません。

事前確認ではインストールを開始しません。「开始安装」（インストール開始）、「开始更新」（更新開始）または「开始命令行安装／更新」（CLI のインストール／更新開始）を明示的に選びます。Windows のベンダーウィザードは「下载并打开安装窗口」（ダウンロードしてインストーラーを開く）を使います。公式ウィザードを完了し、インストール状態とバージョンを更新してください。ウィザードが開いたことはインストール完了の証拠ではありません。

開始前に「暂不开始」（今は開始しない）を選ぶ、または説明を閉じると、タスクは開始されません。開始後に説明やウィンドウを閉じたりページを切り替えたりしても、バックグラウンド処理のキャンセルにはなりません。進行表示にキャンセル操作がある場合だけキャンセルを要求できます。公式ウィザードを開いた後、FyAgent はそのウィンドウを停止しません。

結果が不明、確認できない、または進行中の場合は、現在のタスク表示を残し、インストール状態の更新または再スキャンを行います。場所が変わった場合は対象を選び直します。復旧が必要な未確認結果を別のインストールで置き換えることはできません。検出された状態、バージョン、タスク結果をそれぞれ確認し、説明を閉じたこと、ウィザードを開いたこと、再クリックを完了や復旧の証拠にしないでください。
