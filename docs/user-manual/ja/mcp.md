# MCP 管理

## サービスの追加

「MCP 管理 → 添加 MCP」で一意の ID、名前、必要に応じて説明とタグを入力します。

「快速配置」では転送方式に合わせて入力します。

- `stdio`：コマンド、1 行につき 1 引数、任意の作業ディレクトリ、環境変数（`KEY=VALUE`）。
- HTTP / SSE：接続 URL と必要なヘッダー（`Name: Value` または `Name=Value`）。

「JSON 编辑」で単一サービスの設定を入力する方法もあります。保存前にソフトウェアへの割り当てを確認します。既存サービスは詳細の「编辑」で変更します。

## 検索と取り込み

「发现」でカタログを検索し、説明、認証、実行環境の要件を確認します。対象を選び、必要なパラメーターを入力してインストールします。Node.js / npx や uv / uvx が必要な場合は先に準備してください。

「导入现有」は既存ソフトウェアの MCP 設定を読み込みます。「已安装」で取り込み件数と内容を確認します。

## 割り当てと管理

サービスを選び、割り当て欄で対象ソフトウェアを有効・無効にします。対象の MCP 一覧を更新して呼び出しを試してください。設定保存後は実行環境、認証情報、遠隔サービスの利用可否も確認します。

「重新配置」は既存設定を上書きするため、手動変更を確認してから確定します。「删除」は管理一覧と有効なソフトウェアからサービスを削除します。環境変数やヘッダーに秘密情報がある場合、診断資料を共有する前に伏せてください。
