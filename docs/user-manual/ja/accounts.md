# アカウントと認証

「账号与认证」には「账号」（アカウント）と「软件连接」（ソフトウェア接続）があります。

## 公式アカウントを追加する

1. 「添加账号」を押し、ChatGPT、Grok、GitHub Copilot など、利用可能な種類を選びます。
2. 「仅保存账号」（アカウントのみ保存）または表示された接続用途を選び、ブラウザかデバイスコードのログインを選択します。
3. 表示された公式ドメインを確認して進み、公式ページで操作します。デバイスコードは今回 FyAgent で生成したものを使います。
4. FyAgent に戻って結果を確認します。必要に応じて「继续登录」や状態の更新を使います。

既定アカウントの設定や再ログインもできます。保存後は「软件连接」でソフトウェアとアカウントを選び、変更する認証ファイル、モデルの接続先、バックアップ先を確認して接続・切り替えを確定します。指示があれば対象ソフトウェアを再起動します。

## モデルの接続先を選ぶ

Codex のソフトウェア接続で現在のモデル接続先を確認します。アカウントの接続と、リクエストに使うモデル接続先の選択は別の操作です。画面で変更をプレビューして確定し、結果を確認してください。サブスクリプション設定は [モデル管理](models.md) を参照してください。

切断前に確認画面を読みます。Codex で第三者サービスを復元する操作は、最上位の `model_provider` の使用を復元します。アカウントは一覧に残ります。アカウントを削除すると FyAgent の認証情報と接続記録が削除され、再利用にはログインが必要です。ファイルへの影響は操作画面の内容を確認してください。

状態の取得に失敗した場合は更新します。公式ログイン後も未確認なら、対象ソフトウェアを確認してから続けてください。
