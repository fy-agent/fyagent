# メモリ

「记忆模块」で「长期记忆」（長期メモリ）または「每日记忆」（日次メモリ）を選びます。

## 長期メモリ

OpenClaw または Hermes の `MEMORY.md` / `USER.md` を選び、本文を編集して「保存」します。「尚未创建」と表示されたファイルは保存時に作成されます。

OpenClaw のファイルはワークスペース内にあり、「打开 OpenClaw 工作区」で開けます。Hermes の長期ファイルは `memories/` 内にあり、画面に有効化スイッチと文字数上限が表示されます。上限を超えて保存することもできますが、一部を Hermes が利用できない場合があるため、必要に応じて短くしてください。

## 日次メモリ

OpenClaw ワークスペースの `memory/YYYY-MM-DD.md` を扱います。

- 「创建或打开今天」で今日の記録を開き、編集して保存するとファイルが作成されます。
- 日次記録を検索し、結果を選んで本文を編集できます。
- 「打开记忆目录」でファイルマネージャーを開きます。
- 削除は日付を確認して確定してください。対象のローカルファイルが削除されます。

未保存の編集がある場合、ファイル、メモリ種別、ページの切り替えには確認が必要です。残す内容は先に保存します。再取得に失敗すると前回の内容が表示されるため、読み込みを再試行してから編集を続けてください。

## 手動補完と復元範囲

過去の日付は「打开记忆目录」で対応する `YYYY-MM-DD.md` を探して手動編集し、FyAgent で再読み取りします。履歴の自動再構築やワンクリック補完はありません。必要な履歴は編集前に別途保管します。

FyAgent が既存ファイルを実際に変更すると、同じディレクトリの `<ファイル名>.fyagent.backup` に直前の本文を保存します。次の異なる内容の書き込みでその一世代が置き換わり、同内容の保存では更新されません。新規ファイルには復元する旧本文がありません。Daily ページにワンクリック復元はなく、現在ファイルとバックアップをコピーして比較後、手動で戻し再読み取りします。データベースや全履歴のバックアップではありません。
