# AI ソフトウェア設定

「AI软件配置」を開き、「开始扫描」（スキャン開始）または「重新扫描」（再スキャン）を押します。「进行配置」でソフトウェアの詳細を開き、「查看状态」で実行状態を確認できます。

## インストール・更新・起動

1. 一覧または「安装与更新」で、そのソフトウェアに表示されるインストール・更新操作を選びます。
2. 保存先の選択が表示されたら、対象を選んで確認内容を読みます。複数のインストールが見つかった場合は操作対象を指定します。
3. 完了後、インストール状態とバージョンを確認します。Windows のメーカー製ウィザードが開いた場合は、完了してから更新表示します。
4. インストール済みソフトウェアは「打开软件」で起動できます。

Grok Build のインストールボタンは公式 npm パッケージを使用します。「使用官方命令行安装」で公式 CLI 方式も選べます。方式の変更は確認画面に従ってください。ログインとオンラインサービスの利用可否はネットワークに依存します。

## 機能の設定

詳細のモデル、Skills、MCP、プロンプトを選び、各管理リンクで編集します。Skills と MCP のスイッチは対象ソフトウェアでの有効・無効を切り替えます。プロンプトは項目を選択して有効化できます。

認証欄ではソフトウェアに応じてログイン、Provider 接続、アカウント管理を開けます。公式ログインを完了して戻り、「刷新状态」で確認します。待機を停止しても、開いた公式ログイン画面での処理は続く場合があります。

状態を取得できない場合は再スキャンし、保存先が変わっていたら選び直します。詳しい手順は [モデル](models.md)、[アカウント](accounts.md)、[Skills](skills.md)、[MCP](mcp.md)、[プロンプト](prompts.md) を参照してください。
