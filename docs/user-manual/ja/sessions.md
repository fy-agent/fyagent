# 会話センター

## 閲覧・エクスポート

ソフトウェアと会話を選び、原文または質問・回答プレビューを読みます。元のバージョンで抽出できなくても原文を閲覧できる場合があります。既存パッケージの復元可否は対象バージョンの検証済み書き込み能力で判断します。「导出迁移包」で選択会話を確認して出力先を選びます。

## 取り込み・復元

1. 「导入会话包」で移行パッケージを選択して読み取ります。
2. スナップショット、対象ソフトウェア、本機の絶対パスの作業ディレクトリを選び、競合処理を確認します。対象の書き込みが未検証・非対応なら復元できません。
3. プレビューを確認して「确认恢复至目标软件」を押し、同じ操作の結果を待ちます。画面を閉じても開始済みの書き込みは取り消されません。
4. 復元結果と対象の再読み取りを確認し、対象ソフトで会話を開き、再起動後も確認して新しいメッセージを送ります。

## 四つの事実を分ける

| 表示     | 意味                                                           |
| -------- | -------------------------------------------------------------- |
| 包导入   | パッケージの検証と対応する記録の作成                           |
| 目标写入 | 対象ストレージへの書き込みをシステムが確認。失敗・不明は要確認 |
| 目标读回 | 対象のローカル履歴をシステムが再読み取り検証                   |
| 实机闭环 | 起動、再起動、次のリクエスト、実際の応答の検証を記録ごとに表示 |

再読み取りの成功はモデルの応答を意味しません。「标记：我已手动续聊」はユーザーの説明を保存するだけで、システム段階を進めず、実機証拠を代替しません。

選択したすべての会話について、同じ復元に対応する完全な失敗結果を確認でき、画面でも再試行が許可される場合だけ「重试同一恢复」を使います。結果の欠落・不完全・処理中・不明の場合は「核对恢复回执」と対象の確認を先に行い、重複復元しません。読み取り失敗は更新して確認し、不明な間はパッケージと対象ファイルを保持します。
