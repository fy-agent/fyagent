# モデル管理

「模型管理」の「选择应用」で対象を選び、そのソフトウェアの設定方法に従います。TRAE Work CN の第三者モデルは TRAE Work CN 内で追加し、FyAgent に戻って確認します。

## 入力と保存

1. 設定名（表示される場合）、サービス URL、API Key、モデル ID を入力します。URL は HTTP(S) とし、キーは専用欄に入力します。
2. 「拉取模型」で取得するか、ID を手入力します。WorkBuddy と OpenCode は複数 ID を追加できます。保存予定の一覧を確認します。
3. 「测试连通」でモデルを選び、「开始测试」を押します。リクエストが送信され、少量の利用量が発生する場合があります。
4. 「保存并设为当前配置」または「保存并应用」を押し、変更ファイルとバックアップ情報を確認して保存を確定します。
5. 現在の設定を確認し、案内に従って対象ソフトウェアの更新表示、再起動、または新しいセッションの開始を行います。

Claude Code の URL は、パス重複を避けるため通常は末尾の `/v1` を除きます。サービスの説明に従って確認してください。認証不要のローカルサービスには、表示される「不使用 API Key」を使います。Codex の WebSocket と画像生成拡張はサービスの互換性に合わせて選びます。

上書きや削除前に対象を確認します。外部で設定が変更された場合や保存結果が未確認の場合は、現在の設定を再取得してから続けます。

## サブスクリプションを使う

「使用账号订阅（实验性）」で保存済みの ChatGPT または Grok アカウントを選び、対応モデル ID を選択・入力します。Grok の候補例が利用できるかはサービスの応答で確認します。

Codex は「保存 Codex 订阅配置」の後、「账号与认证」で接続先の変更をプレビューして確定します。他の対象は表示された適用ボタンでファイル変更を確認します。利用中は FyAgent をバックグラウンドで実行してください。完全に終了するとローカル転送が停止します。実際の利用可否と利用枠はサービスの応答に従います。

[アカウント](accounts.md) と [問題への対処](troubleshooting.md) も参照してください。
