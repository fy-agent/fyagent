# 実行状態

「运行状态」でソフトウェアを選び、「重新检查此软件」（このソフトウェアを再確認）を押します。全体を見る場合は「检查全部软件」を使います。名前の検索と状態による絞り込みができます。

結果はインストールと起動、アカウントと設定、接続と利用に分かれます。失敗や未確認の項目から対応し、結果に表示されるリンクでインストール、アカウント、モデル設定へ進みます。

「停止检查」は実行中の確認が終わった後に停止します。個別の失敗はそのソフトウェアだけ再確認できます。前回の結果が残っている場合は確認時刻を見てください。

ローカル確認では遠隔サービスや利用枠をテストしません。5 分を超えた結果は再確認してください。モデルの応答を確かめるには、[モデル管理](models.md) の「测试连通」を使います。インストール、認証、モデル設定を変更した後も対象を再確認してください。
