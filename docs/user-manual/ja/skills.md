# Skills 管理

## インストールと取り込み

「Skills 管理 → 发现」で名前や用途を検索し、説明を確認して対象を選び、インストールを確定します。「已安装」（インストール済み）で詳細と割り当てを確認します。

「更多」（その他）には次の操作があります。

- 「导入本地 Skill」：インストール済みアプリ内の未管理 Skills をスキャンし、項目と有効にするソフトウェアを選んで「导入所选」を押します。
- 「从 ZIP 安装」：ZIP を選び、対象と表示された保存先を確認して進みます。

## 割り当てと更新

Skill を選び、割り当て欄のスイッチで対象ソフトウェアを切り替えます。対象の Skill ディレクトリが変更されるため、結果を確認して対象ソフトウェアで再読み込みします。

「检查更新」で更新を確認し、個別更新または「更新全部」を実行します。一括操作後は成功・失敗件数を確認し、失敗項目を再試行してください。

## バックアップと保存先

アンインストールは管理一覧と有効なソフトウェアから Skill を取り除きます。既存のバックアップは「更多 → 备份恢复」で復元先と項目を選び、「恢复」で戻せます。バックアップ削除前に不要であることを確認します。

「更多 → Skill 设置」で自動、シンボリックリンク、コピーの同期方式を選んで保存できます。保存先の移行操作は FyAgent または統一ディレクトリへ移動します。確認内容を読み、移行中はアプリを終了せず、完了後に失敗項目を確認してください。

既定の保存先は `~/.fyagent/skills/`、アンインストールのバックアップは `~/.fyagent/skill-backups/` です。実際の場所は詳細表示を確認してください。
