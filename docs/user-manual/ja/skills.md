# Skills

## インストール・取り込み

「发现」で検索し、説明と対象を確認してインストールします。結果は「已安装」で確認します。「更多 → 从 ZIP 安装」はファイル選択後に対象を確定します。

「更多 → 导入本地 Skill」では未管理の項目を選び、ソフトウェアのスイッチを調整し、「预览导入」で一覧と対象を確認して「确认导入」を押します。元のディレクトリは残ります。リンク元は読み取り、通常のディレクトリへコピーできます。

## 割り当てと失敗時の対処

単一項目は対象スイッチで操作します。「批量分配」では絞り込み・選択、対象一つと有効/無効の指定、プレビュー、確認の順で進めます。完了は保存状態の再読み取りで確認します。状態が変わった場合は再プレビューします。失敗しても一部書き込み済みの場合があるため、実際の状態を更新してから未完了項目を選び直します。

取り込み結果が「已入库」なら「已安装」で割り当てを修復し、再取り込みしません。登録できたか不明な場合は「刷新并查看已安装」で先に確認します。未管理と確認できた未完了項目だけ再選択してプレビューします。

詳細にリンク元と読み取り専用の対象が表示されます。親ディレクトリのリンクも含め、リンクは変更・削除しません。リンク対象のスイッチは操作できませんが、通常の対象は利用できます。更新・削除が拒否されたら元のディレクトリを保持し、通常のディレクトリを使ってください。FyAgent の再読み取りだけでは外部ソフトの読み込みは証明できません。対象ソフトでも再読み込みして確認します。

## 更新・バックアップ・保存先

「检查更新」から単一更新または「更新全部」を実行します。一部だけ成功した場合は件数を確認し、失敗項目を対処します。削除の確認を読み、毎回バックアップが作成されるとは考えないでください。「更多 → 备份恢复」は実在する一覧のバックアップを対象選択後「恢复」で復元します。

「更多 → Skill 设置」で自動・シンボリックリンク・コピーを選択します。保存先移行は確認が必要です。リンク保護による拒否では移行前に停止し、通常の I/O エラーでは項目ごとの部分完了があります。既定のライブラリは `~/.fyagent/skills/`、共通ライブラリは `~/.agents/skills/`、削除時のバックアップは `~/.fyagent/skill-backups/` です。
