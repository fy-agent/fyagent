# 2.1 Agent ツールのインストールとバージョン確認

FyAgent では、PC に入っている Agent ツールを確認し、その多くをインストールできます。入口は「設定 → About → ツール管理」です。

## 対応範囲

バージョン検出は Claude Code、Codex CLI、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes を対象にします。現在のバージョン、新しいバージョンの有無、Windows・WSL・macOS・Linux のどこで見つかったかをカードに表示します。

Claude Code、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes は、この画面からインストールまたは更新できます。Codex CLI のカードはバージョン確認専用で、インストールと更新は行いません。Codex CLI は公式の配布手順で導入してください。

## ツールをひとつインストールする

1. ツール管理を開き、バージョン確認が終わるまで待ちます。
2. 未インストールのカードで「インストール」を選びます。
3. コマンドの完了後、FyAgent がもう一度バージョンを確認します。終了コードが成功しただけでは完了扱いにしません。
4. バージョンが空のままなら、別の場所へのインストールや、選択中の shell から見えない PATH を診断結果で確認します。

複数のグローバルパッケージ操作が同時に環境を書き換えないよう、インストールまたは更新は一度に一組だけ実行されます。

## インストールコマンドをまとめてコピーする

「インストールコマンドをコピー」は、現在の OS に合うコマンドをクリップボードへ入れます。自分のターミナルで内容を確認してから実行できます。Windows と Unix 系では内容が異なり、対象は管理可能な 6 ツールのみです。Codex CLI は含まれません。

コピーした内容も、確認なしで実行するための許可ではありません。ダウンロード元、パッケージマネージャー、ターミナル権限を先に確認してください。

## Windows と WSL

WSL に入れたツールでは、`sh`、`bash`、`zsh`、`fish`、`dash` と、`-lic`、`-lc`、`-c` の起動フラグを選べます。設定を変えると、新しい条件でバージョン確認が走ります。

普段そのツールが動く WSL shell と同じ設定を選んでください。分からない場合は、いつもの WSL ターミナルで `--version` を実行し、その shell を FyAgent に設定します。

## 結果を確かめる

確実な確認には、カードにバージョンが出ることと、実際に作業するターミナルで起動できることの両方が必要です。インストーラーが成功してもバージョンが空なら、PATH、Node.js ランタイム、shell のどれかで実行できていない可能性があります。[更新とインストール競合の診断](./2.2-update-diagnose.md)へ進んでください。
