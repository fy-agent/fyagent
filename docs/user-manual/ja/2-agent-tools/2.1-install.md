# 2.1 Agent ツールのインストールとバージョン確認

FyAgent では、PC に入っている CLI ツールを確認し、**Grok Build** をインストールまたは更新できます。入口は「設定 → About → ローカル環境チェック」です。Claude Desktop、Codex Desktop、OpenCode Desktop は Agent ページで管理し、設定に CLI コマンドを貼り付けて導入しないでください。

## 対応範囲

バージョン検出は Claude Code、Codex CLI、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes を対象にします。カードには現在のバージョンと、検出できた新しいバージョンを表示します。

設定からインストールまたは更新できるのは **Grok Build** だけです。他の CLI カードは参照専用です。デスクトップアプリは Agent ページの該当製品から導入します。

## Grok Build をインストールする

1. ローカル環境チェックを開き、バージョン確認が終わるまで待ちます。
2. Grok Build のカードで「インストール」を選びます。既定では xAI 公式 npm パッケージを、国内 npm ミラー経由で入れます。
3. 公式 CLI インストーラーが必要な場合は「公式 CLI でインストール」を選びます。既存の導入方法は自動では切り替わりません。
4. 完了後、FyAgent がもう一度バージョンを確認します。処理が終わっただけでは完了扱いにしません。
5. バージョンが空のままなら、診断結果でインストール元の競合を確認します。

インストール成功は、この PC に Grok Build CLI があることだけを意味します。ログインとオンライン推論は、xAI のサービスがネットワークから届くかどうかに依存します。

Grok Build のインストールまたは更新は一度に一組だけ実行されます。

## 結果を確かめる

カードにバージョンが出ることと、実際に作業するターミナルで `grok` が起動できることの両方が必要です。バージョンが空のままなら、[更新とインストール競合の診断](./2.2-update-diagnose.md)へ進んでください。
