# Gamma 赛前说明摘要（2026-08-27）

## 活动基线

- 活动提供 A/B/C/D 四款 ESP32-S3 板卡。
- 统一目标是通过开源 SDK `agent_link` 接入 ROROLEE App 与云端 AI Agent。
- 板卡数量有限：A × 15、B × 10、C × 5、D × 10。
- 三人组建议分工为硬件/固件、Agent/云端、交互/展示或结构设计。
- 赛事建议提前安装 ESP-IDF v5.5.4 并完成一次构建。

## 板卡 C 摘要

- 定位：多传感器融合、环境感知和交互装置；上手难度中到高。
- 规格：ESP32-S3、多合一套件、27 个子模块、21 种模块、排针 + Grove、3.3V 模块工作电压、6–12V 外部供电、PCB 250 × 175 mm、固定孔 244 × 169 mm。
- 适合方向：无接触/体感交互、智能安防站、环境/能耗监测、摇杆/编码器交互装置。
- 现场不提供电机，因此依赖小车、机械臂或运动机构的方案不可作为本次主路径。
- 页面称已有 `gc2145-camera` 适配，可做 GC2145 摄像头到屏幕的实时预览。

## 与当前官方仓库的差异

Gamma 页面还描述了 Wi-Fi transport、SoftAP 配网和设备直连 Agent。2026-08-27 复核 `DeotalandDev/Agent_link` 当前 HEAD `3c93ecfcdc473c952a0e85d9797c2663e9ba7d87` 的 README 后发现：

- BLE transport 已实现；
- Wi-Fi / USB backend 仍为 scaffolding；
- `push_video` 只有接口，需要未来的 Wi-Fi / WebRTC backend；
- 语音和设备 I/O 是“implemented, not yet validated on hardware”。

因此本项目把 Gamma 页面作为赛事意图和选型说明，把当前官方 GitHub 主分支作为 SDK 实现状态基线。
