# FyHelm

> 已将特性移植到 https://github.com/fy-agent/fyagent/tree/demo/shurufa ，后续将继续在 https://github.com/fy-agent/fyagent/tree/demo/shurufa 进行开发。

FyHelm 是本次 TiDB × Deotaland 智能硬件黑客松的项目资料仓库。当前基线是：

- **硬件方案**：板卡 C，ESP32-S3 AIoT 套件。
- **实体外观**：海绵宝宝主题“活屏脸”桌面伙伴；屏幕承担眼睛与情绪表达。
- **交付策略**：只打印一个实体方向；其余外观方向只做 CAD 渲染，优先保证明日下午前获得可展示样机。
- **连接基线**：先按 `agent_link + BLE + ROROLEE` 闭环；Wi-Fi 与视频能力不得在实机验证前写成已完成。

> 海绵宝宝主题仅用于黑客松概念展示。若进入商业化，应替换为原创角色资产。
