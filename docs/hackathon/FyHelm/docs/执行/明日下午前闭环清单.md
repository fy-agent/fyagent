# 明日下午前闭环清单

## 关闭条件

- [ ] 板卡路线确定：整板入壳，或核心板 + 独立模块。
- [ ] [工程测量表](工程测量表.md)必填项完成并双人复核。
- [ ] `agent_link` 在目标板上完成 ESP-IDF build；不以文档声称替代构建结果。
- [ ] 20–35 分钟接口试片打印完成，真实硬件逐项装入通过。
- [ ] 主壳切片时间可接受，并进入共享打印队列。
- [ ] 主壳与背盖可装配；旋钮可转、按键可按、USB 线可插拔。
- [ ] 屏幕至少有待机、执行、成功、失败四种可拍摄状态。
- [ ] BLE 能被 App 发现并连接；核心演示流程可重复跑通。
- [ ] 准备一个失败路径：BLE 断开或云端失败时，设备给出明确本地状态。
- [ ] 获得正面、45°、侧面、背面和运行状态照片，以及 20–40 秒演示视频。
- [ ] PPT 标明角色 IP 边界和未完成能力，不把 Wi-Fi / 视频写成已闭环。

## 早期环境预检

1. 确认现场打印机型号、喷嘴、可用材料、最大成型尺寸和当前排队时长。
2. 确认是否有黄色 PLA；若没有，立即锁定单色壳 + 黄色贴膜/喷涂替代方案。
3. 在开发电脑完成 ESP-IDF 环境检查，目标版本优先服从赛事说明；记录实际 `idf.py --version`。
4. 拉取 `Agent_link` 当前主分支，记录 commit；选择实际可用 Board Type。
5. 确认 ROROLEE App 已安装、蓝牙权限正常、手机可用于整段演示。
6. 确认供电线、备用 USB-C 线、双面胶、锉刀、美工刀、卡尺和贴纸打印条件。

## 执行顺序

### 1. 冻结硬件包络

- 实测整板 / 核心板、LCD、编码器、4 个按钮、麦克风、LED、USB 和供电入口。
- 先解决 GPIO 与供电冲突，再冻结外壳坐标。
- 若使用整块 250 × 175 mm 扩展板，先确认打印机成型尺寸能容纳主壳。

### 2. 建接口试片

- 只建关键开孔、一个卡扣和局部壁厚。
- 试片通过的定义：器件能无破坏装入；按钮不卡；旋钮不摩擦；USB 插头完全到位；卡扣能开合一次。

### 3. 冻结实体面

- 试片通过后冻结主壳轮廓、开孔和背盖接缝。
- 此后只允许修复阻断打印或装配的问题；表情、贴纸和 PPT 可并行推进。

### 4. 正式打印与并行工作

- 立即排主壳；再排背盖和旋钮帽。
- 打印期间完成屏幕状态、贴纸、走线、演示数据和讲述脚本。
- 另外两个外观方向只输出渲染，不占用打印机。

### 5. 实机验收

- 冷启动一次、连续演示三次、断开 BLE 一次、重新连接一次。
- 拍摄前清理支撑残留、线材和桌面杂物。
- 只有真实输出通过后，才更新 README 中的完成真相。

## 降级顺序

若时间不足，按以下顺序砍掉内容：

1. 手臂、腿、立体鼻子；
2. 背盖卡扣，改隐藏双面胶；
3. 复杂海绵孔，仅保留贴纸；
4. 第二、第三渲染方向；
5. 非核心传感器。

不得砍掉：屏幕开窗、基本装配、供电、BLE 核心流程、失败状态和可拍摄外观。
