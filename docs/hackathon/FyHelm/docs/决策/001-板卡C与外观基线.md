# 决策 001：板卡 C 与外观基线

## 结论

1. **本次选择的“C 版”指硬件板卡 C：ESP32-S3 AIoT 套件。**
2. 上一轮外观讨论也使用了 A/B/C 编号。为避免混淆，后续统一写成“板卡 C”和“外观方向 A/B/C”。
3. 实体打印采用**外观方向 A：海绵宝宝“活屏脸”桌面伙伴**。
4. 外观方向 B、C 只做 CAD 渲染，不进入本次正式打印队列。

## 为什么这样定

- 用户的首要成功标准是第一眼惊艳、适合照片和路演，评委主要观看，不需要拆机或高频操作。
- 板卡 C 有 LCD、旋转编码器、四个按键模块、数字麦克风、LED、ESP32-S3 主控及多种传感器，能覆盖现有外露器件需求。
- 共享 FDM 打印机且截止时间是明日下午；只做一个实体方向才能保留试片、失败和重打窗口。
- “活屏脸”把屏幕直接变成角色眼睛与情绪中心，减少立体五官和多色打印，镜头识别度高。

## 外露器件与角色映射

| 硬件 | 外观映射 | 本轮边界 |
| --- | --- | --- |
| LCD | 两只眼睛与动态表情 | 视觉中心；必须按实际亮屏区开窗 |
| 旋转编码器 | 右脸颊的黄色“泡泡旋钮” | 次级焦点，不改变已冻结的硬件坐标 |
| 确认键 | 红色领带 | 可用贴片覆盖按钮帽，不做复杂一体件 |
| 其余 4 个按钮 | 裤腰控制块或海绵孔 | 保持统一边框和足够手指间距 |
| 数字麦克风 | 雀斑或海绵孔 | 只留少量较大孔，不做密集微孔 |
| LED / WS2812 | 单一状态灯 | 只承担一种清晰状态，不增加多处装饰灯 |
| USB / 电源 | 后置凹槽 | 正面不见线；孔位要按插头外壳而非母座尺寸验证 |
| 散热孔 | 侧面海绵孔或背部水平槽 | 设备低热，仅保留最低必要通风 |

## 结构基线

- 黄色单色主壳，背部敞开打印；电子件从背后装入。
- 白衬衫、棕裤、红领带、牙齿、睫毛和嘴部线条使用贴纸或薄片。
- 背盖采用“定位舌 + 两个浅卡扣 + 开启缺口 + 阴影缝”；卡扣只防脱，台阶负责定位和承重。
- 手臂、腿、鼻尖等孤立结构不与主壳一体打印；只有主壳成功后才考虑附加。

## 当前不做的事

- 不同时打印三个完整外观。
- 不做五色 AMS 正式打印。
- 不把摄像头、电机、扬声器或未明确的传感器擅自加入外露范围。
- 不把未经实机验证的 Wi-Fi、视频或云端直连能力写成完成项。

## 需继续确认

- “一个后置 USB-C”是否能同时满足板卡 C 和已选模块供电；官方整板资料还提供 6–12V 外部供电入口。
- 4 个按钮是否拥有 4 个独立 GPIO；现有赛前说明只给出了上拉键 IO12、下拉键 IO14 的示例，且 IO14 与 MQ2 数字输出、SD MOSI 有潜在复用冲突。
- 是否使用整块 250 × 175 mm 扩展板，还是只拆出 ESP32-S3 核心板与所需模块。两者会导致完全不同的外壳体积。
