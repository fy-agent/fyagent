# 黑客松 3D 打印产品外观调研

## 调研边界

原对话报告检索返回 354 个页面，去重后有效样本超过 200 个，并深读 20 个高信号来源。但当前可读取对话没有附带逐条 URL 清单，只有若干会话内引用编号。因此本仓库归档的是**已有结论与当前可重新核对的官方来源**，不把“200+ 来源”冒充为已完成的可审计 bibliography。

## 核心判断

在明日下午截止、共享 FDM 打印机、多团队排队的条件下，完成度来自克制：

- 实体只做一个方向；另外两个方向只做渲染。
- 先验证接口和公差，再排完整主壳。
- 轮廓、色块和动态表情负责“惊艳”；复杂卡扣、多色换料和孤立细节不承担核心价值。
- 采用“黄色单色 3D 主壳 + 屏幕动态表情 + 彩色贴片”的混合材料方案。

## 推荐实体：海绵宝宝“活屏脸”

视觉中心是屏幕中的两只大眼与表情。旋钮降为右脸颊的次级焦点，确认键映射为红色领带，四个按钮映射为裤腰控制块或海绵孔。麦克风孔隐藏为雀斑或海绵孔，状态灯只承担一种状态。

动态表情至少覆盖：

- 待机：眨眼；
- 执行：专注；
- 等待审批：紧张；
- 成功：开心；
- 失败：沮丧或故障表情。

## 打印与装配策略

### 主壳

- 正脸朝向打印平台，背部完全敞开。
- 普通大面壁厚 1.6–2.0 mm；卡扣根部和受力区约 2.4 mm。
- 外轮廓圆角 4–8 mm；海绵波浪边起伏 2–4 mm；凹孔深 1–1.5 mm。
- 正面不放孤立悬空装饰；睫毛、牙齿和鼻尖不与主壳一体打印。

### 背盖

- 两个定位舌承担位置约束；内侧台阶承重。
- 两个长而浅的卡扣只负责防脱。
- 设置开启缺口和一圈阴影缝，主动隐藏翘曲与装配误差。
- PLA 卡扣若不可靠，可用隐藏双面胶作为黑客松展示保险。

### 建议公差起点

| 位置 | 建议 |
| --- | --- |
| 板卡非定位轮廓 | 向外放宽 1.0 mm |
| 插件、飞线、焊点上方 | 放宽 1.5–2.0 mm |
| 屏幕可视窗口 | 每边比实际亮屏区多 0.3–0.5 mm |
| 按钮开孔 | 每边多 0.4–0.6 mm |
| USB-C 外壳孔 | 每边约多 1.5 mm，并验证插头塑胶外壳 |
| 壳体滑动接触面 | 单边 0.3–0.5 mm |
| 背盖外围 | 总间隙约 0.6–0.8 mm |
| 旋钮轴孔 | 不直接套通用值，先打印试片 |

以上都是未知 FDM 设备下的起点，不是免测试的最终尺寸。

## 最短验证闭环

1. 从正面板截取一个小型“接口骨架”，包含屏幕窗口、旋钮孔、一个普通按钮、确认键、卡扣片段和 USB-C 孔。
2. 将试片打印控制在 20–35 分钟。
3. 用真实硬件逐个装入，检查插头、按压、旋转、卡扣和拆卸。
4. 修正一次后立即提交完整主壳，停止继续雕刻非核心装饰。
5. 主壳打印期间完成表情动画、贴图、PPT 渲染、走线和拍摄脚本。

## 建议切片起点

- 使用现场已经验证过的 PLA / PLA+ 默认 profile。
- 0.4 mm 喷嘴；0.24 mm 层高，极端赶时间可用 0.28 mm。
- 四道外墙；壳体内部 0–10% 填充。
- 接缝放到背面边角。
- 大平面有翘曲风险时加 brim 或 mouse ears。
- 可见正面不生成支撑。

## 三个外观方向

| 方向 | 形式 | 本轮状态 |
| --- | --- | --- |
| A：活屏脸 | 屏幕承担眼睛与情绪；旋钮为泡泡控制器；确认键为领带 | **实体打印** |
| B：海绵宝宝控制台 | 静态大眼和嘴，屏幕放胸口，偏 Cyberdeck | CAD 渲染 |
| C：完整桌面摆件 | 增加手臂、腿、鞋和立体鼻子 | CAD 渲染；不打印 |

## 高频失败模式

1. 完整角色一体打印，任一肢体失败拖累整件。
2. 五色 AMS 打印，换色、耗时、废料和污染吞掉容错窗口。
3. 正脸使用支撑，拆除痕迹进入镜头中心。
4. 卡扣零间隙，导致装不进或扣上后打不开。
5. 以屏幕模组外框中心代替实际亮屏区中心，造成视觉偏斜。
6. 等全部装饰完成后才排队，错过共享打印机窗口。
7. 只按 USB-C 母座金属尺寸开孔，忽略插头塑胶壳与线缆弯曲。
8. 把官方示例或 SDK 自报状态当成 FyHelm 的实机完成证据。
