# FyAgent 对外视觉资产计划

## 先说清楚要解决什么

FyAgent 的功能不缺，缺的是一眼能懂、又经得起核对的表达。对外页面不能只放长功能清单，也不能用一张漂亮的概念图代替真实产品。后续资产固定分成两层：概念插图负责解释“为什么有用”，真实运行时截图负责证明“产品确实这样工作”。

主叙事沿用 VibeKey 值得保留的部分——一个动作对应一个清晰状态——但彻底放弃硬件外形。FyAgent 是桌面软件，不是键盘、USB Hub 或实体控制器。

## 视觉基调

- 背景：深石墨 `#0B1017`，浅色版本使用暖白和低对比灰。
- 主信号：青绿 `#27D9C4`、电蓝 `#2F7DFF`。
- 状态：绿色只表示健康，橙色表示需要注意，红色表示失败；文字或图形必须同时解释状态，不能只靠颜色。
- 材质：克制的哑光工程表面、少量雾面层次、清晰的数据轨道。
- 构图：一个主焦点，一条可追踪的信息流，给标题和 CTA 留真正能用的安全区。
- 避免：紫色 SaaS 渐变、赛博霓虹、密集假 UI、随机漂浮卡片、硬件插头、生成文字和近似第三方 Logo。

- [v2 触觉化软件编排样例](./visual-direction-sample-v2.md) 保留为 `superseded` 记录。它验证了构图和材质方向，但左右线路、端口和弯折规则不一致，不能继续作为当前候选。
- [v1 统一管理样例](./visual-direction-sample-v1.md) 保留为 `superseded` 记录。它的构图可用，但模型生成了近似 FyAgent 标志，因此不能继续作为候选。
- [VibeKey 对照审计](./vibekey-reference-audit.md) 记录了继承、改造和放弃的边界。历史参考只影响叙事纪律与材质，不进入当前产品代码，也不作为已交付功能证据。

## ChatGPT 生图工作流

1. 先选资产类型，并在[提示词卡](./prompts/README.md)中复制最接近的母版。
2. 一次只解决一个视觉问题。需要改构图、材质和主题时分轮做，不在一条修订提示里同时大改。
3. 生图阶段不生成 Logo、标题、按钮、流程标签、第三方图标和真实 UI。模型只负责背景、材质、抽象关系和插图主体。
4. 如果使用 `assets/fyagent.png`，它的角色只能是项目自有品牌参考或后期合成素材；禁止让模型描摹、变形或重画。
5. 输出后记录提示词、模式、参考图、尺寸、SHA-256、状态和限制。没有这些记录的图片不能进入发布目录。
6. 用原始 Logo 和 HTML/SVG 添加文字。每个画幅独立排版并检查安全区，不用自动裁切代替设计。
7. 概念图旁边必须放真实运行时截图。截图无法取得时，宁可暂时不放，也不能用生成图、浏览器 mock 或旧品牌画面替代。

## 文件与状态

建议状态只用以下几种：

| 状态                  | 意思                                               |
| --------------------- | -------------------------------------------------- |
| `exploration`         | 方向探索，不对外使用                               |
| `superseded`          | 已有替代方案，只保留追溯                           |
| `concept_candidate`   | 可继续评审，不等于批准发布                         |
| `approved_background` | 只批准作为无字背景或插图主体                       |
| `runtime_screenshot`  | 来自真实桌面运行时，已完成脱敏和版本记录           |
| `final`               | 文案、Logo、版权、裁切、可访问性和渠道尺寸全部通过 |

最终文件放进按渠道命名的发布目录，概念原图留在 `assets/samples/` 追溯。文件名不用 `final-final` 一类口头状态，状态写在同名 Markdown 记录中。

## 发布检查

- 产品名称、支持工具数量、动作范围和版本文案都能从当前发布证据核对。
- 原始 FyAgent Logo 没有被修改、重画、拉伸或当作纹理。
- 没有第三方近似商标、生成文字、虚构 UI 或未经授权的历史素材。
- 概念图明确标注为插图，真实界面明确标注系统、语言、版本和证据等级。
- 16:9、1200×630、4:5、1:1 均独立看过主体、文字安全区和移动端裁切。
- 图片有可用 alt 文本，文件体积适合渠道，PNG/WebP/AVIF 的选择有实际预览依据。

本轮已经完成方向、提示词和样例，但没有把概念图升级为发布资产。当前主机的 Windows C++ 与 WebView2 预检已经通过；真实截图仍要按任务卡固定三语数据并完成脱敏复核。README 已先停止引用旧品牌截图，避免用错误证据凑齐版面。
