# 本轮迭代范围与验收

状态：最终隔离 macOS VM 应用验收通过。[PR #361](https://github.com/fy-agent/fyagent/pull/361) 保持草稿，独立提交规范修复已通过 28 项检查，远程 CI 待回读；尚未合并或发布。

本次把 Windows 主线修复与 CC Switch 4.0.4 迁移收拢，并完成聚合入口、账号额度和对应页面的整合。应用版本仍以项目版本配置为准，本说明不创建版本标签。

## 包含的能力

- 使用迁移后的 live/Aggregation 实现管理模型候选和组合，保留请求切换、退出恢复及已移除成员的拒绝行为。
- OpenAI/xAI 账号额度查询与手动刷新复用既有接口；凭据续期遵守原有归属，不新增轮询或认证框架。同账号重新登录更新 FyAgent 保存的凭据。
- 账号列表仅把实际连接显示为“已连接”，等待重启或仅保存账号单独显示；页头只展示一条优先状态，具体问题保留在账号和软件连接详情。
- 保留主线 Windows 安装修复，以及 Gemini 现有 settings 无法解析时不覆盖文件的保护。

Pi/Mcode 延续原迁移任务的延期范围，不列为本次已完成的界面能力验收；本轮不声称覆盖 4.0.4 的所有界面功能。

Windows/Grokbot 的迁移与评审、官方 Grok CLI 的冲突/账号能力实现，以及 Codex 的整合、简化和独立回读共同构成本次候选。发现与上游同源的问题时优先反馈上游；本次重新登录凭据替换问题属于 FyAgent 自有账号管理。

私人账户数据、服务排障日志和本地回滚记录不进入公开材料。第三方服务可用性与 FyAgent 客户端验收分别判断。
