# FyAgent 下一轮交互草图

打开 [fyagent-next-iteration.html](./2026-10-04-fyagent.html) 即可浏览。独立 HTML，无外部依赖。所有路径、账号、内容与结果都是固定虚构数据；页面不读取真实文件、密钥或网络，不写入实际配置，不持久化状态。刷新页面会重新开始。

这是一份产品决策草图，不是 FyAgent、Codex 插件或上游迁移的实施成果。旧研究只作为场景输入，不能据此判断当前项目已经实现了哪些行为。CC Switch v4.0.0 相关模式仅作预发布候选交互推演，其来源核验见本任务主报告。

## 三个主视图

1. **桌面入口**：保留软件发现、模型与账号、Skills、MCP、提示词与记忆。工作区包含“Skill 分配”和“模型与模式”两个页签；未展开的保留入口可点击查看边界说明。
2. **Codex 对话**：对话发起和解释任务，右侧借用宿主已有差异审阅的表达方式呈现完整内容。它只是独立 HTML 中的示意，并未嵌入 Codex。
3. **双目标面板 · 比较**：用更集中的目标对照承接同一任务。只有薄入口仍持续难以辨认对象与状态时，才考虑增加这块面板。

三个视图共用同一轮 Skill 任务状态，便于比较操作位置，而不改变规则和输入。

## 建议体验顺序

1. 桌面 → Skill 分配。查看 v1 → v2 的源差异、Codex 当前副本和 Claude 冲突。
2. 决定 Claude 采用新版，或本轮跳过它。只有选中目标、解决冲突后才能生成预览。
3. 核对完整拟写入 `SKILL.md`、目标虚拟路径、保留／替换内容，勾选确认后应用。
4. 查看逐目标结果、本次备份，单独恢复某个已更新目标。恢复需要再次核对原文并确认。
5. 切换到 Codex 对话或比较面板，观察相同状态如何呈现。

页面右上的“演示情景”可以切换：

| 情景 | 草图中的边界 |
| --- | --- |
| 正常更新 | 确认前不应用；结果按目标展示；宿主重载未验证。 |
| 预览过期 | 模拟 Claude 在预览后新增术语偏好；旧预览的应用禁用。重新检查或返回调整都需要重新决定冲突、重新预览和确认。 |
| 备份失败 | Claude 备份失败时，所有选中目标均保持未写入。 |
| Claude 写入失败 | Codex 可成功，Claude 在写入前失败并保持原样；可单独恢复成功目标，不宣称多目标一起成功。 |

“复制与链接有什么不同”解释独立副本与共用主库的影响范围。本例只演示复制模式、单个 `SKILL.md`；实际实现还需检查整个 Skill 目录、链接关系、旧版基线和逐文件失败。草图不代表已经解决跨目录或多文件原子性。

## 模型入口

- 点击“直连／路由／聚合”只浏览方案，当前模拟模式保持不变。
- 聚合示意把模型以“名称 · 来源”列出，默认供应商须来自选中的候选来源。
- “查看拟启用方案”先显示目标、模式、默认供应商与模型列表，勾选核对后才能明确启用。
- 聚合不提供故障转移。路由的故障转移需要另行配置和验证，本草图未模拟自动切换。
- 页面仅改变内存中的模拟模式；启用后的客户端列表重载未验证。方案摘要不是真实配置差异，也不是可执行配置模板。

## 本轮验证证据

验证记录见 [verification.json](./2026-10-04-verification.json)。证据为 **静态检查 + 非浏览器状态逻辑检查**，不是正式 UI 验收。

- 已核对内联脚本语法、无外部资源、无网络调用、无真实文件或持久化存储接口。
- 使用最小页面对象替身执行脚本，检查目标选择、冲突处理、确认保护、过期预览、备份失败、部分失败、逐目标恢复、三入口共用状态、模型浏览与明确启用等状态转换。
- 页面提供原生按钮、带标签的表单、原生对话框和焦点样式。**真实浏览器按钮事件、Tab／Enter／Escape 行为、实际排版和窄屏效果未验证。**
- 浏览器工具先报告子 Agent 不支持可见 IAB，再拒绝隐藏 IAB 的本地 `file:` URL，并明确禁止绕路。因此没有转用本地服务或其他浏览器规避该限制。
- 无 `runtime_screenshot`，无 `pixel_diff`。未启动或修改 FyAgent；未验证真实插件、工具连接、配置更新、备份恢复或宿主重载。

后续浏览器验收应在允许打开本地 HTML 的环境中，逐一走完上述四种情景、恢复确认、模型默认来源校验，以及键盘和窄屏阅读。
