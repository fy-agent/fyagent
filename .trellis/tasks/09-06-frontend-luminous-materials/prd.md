# 清亮色彩与低成本玻璃材质

## Goal

统一明亮蓝灰语义色彩，改善玻璃边缘与磨砂层次，并验证透明度降级、对比度及渲染成本

## Requirements

落实父任务R1/R2/R3/R7/R8：更明亮且不刺眼的蓝灰界面，深色正文、可读辅助信息、
薄磨砂与液态边缘的清楚层次。保留当前布局、圆角、字阶、四尺寸/窄容器行为。
玻璃材质必须在无高级折射环境也成立，不用全屏截图、WebGL或高频噪声生成。

## Acceptance Criteria

- [ ] 七页及模态的默认、选中、hover、聚焦、警告/错误及禁用状态成套检查；普通文字4.5:1、关键控件边界3:1。
- [ ] 与未修改版本同夹具截图对照，页面主体明显更明亮；模态内有边缘与薄磨砂层次，而非只有外围模糊。
- [ ] 默认清亮蓝灰并搭配深色正文；不增加主题切换功能，不用整页brightness滤镜。
- [ ] 玻璃只在现有适配器内集中实现；增强态与基础态可连续交接，无按动画完成瞬间突换背板。
- [ ] 无滤镜、减少透明度、强制颜色均保留可读和可操作降级；普通长文本、320px容器和四桌面尺寸回归通过。
- [ ] 新增光学无持续RAF、页面复制或嵌套实时材质；按父任务预算记录导航和模态暖态/冷态成本。
- [ ] 更新surfaces-responsive/visual-language/reuse等实际所属SPEC后提交、归档。

## Scope Boundary

该任务先于连续动效子任务。只改视觉角色与材质适配，不改业务状态、原生接口、
布局流程或来源生命周期。原始“浅色=所有文字白色”的组合不得残留；不更改品牌
图标图形来迎合阈值，必要的可读承托使用既有品牌框。
