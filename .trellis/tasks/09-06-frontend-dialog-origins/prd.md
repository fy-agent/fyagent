# 补齐模态来源与瞬态触发链路

## Goal

全量盘点 Dialog 包装与触发入口，补齐异步、菜单及嵌套场景的显式来源，并验证回到持久触发器

## Requirements

所有用户触发模态沿用共享来源/返回动画，重点包含账号移除的异步预览。
静态originRef接入与实际运行时动画都必须检查，不能只补标签。

## Acceptance Criteria

- [ ] 所有Dialog/包装/触发路径形成清单，账号移除快速与延迟preview都有真实中间帧。
- [ ] 补齐遗漏的Trust/菜单/嵌套来源；瞬态来源保留安全几何或其明确持久触发关系，不猜来源。
- [ ] 保留取消、焦点、草稿、减少动态效果和失效来源降级，不复制敏感内容。
- [ ] 新增防漏静态与行为检查，完整回归和性能通过，SPEC/提交/归档。

## Constraints

沿用Motion/Radix/WAAPI，不增加第二套focus/animation框架。
