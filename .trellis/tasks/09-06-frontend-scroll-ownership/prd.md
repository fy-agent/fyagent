# 恢复页面与页签的实际滚动可达性

## Goal

核对七路由和页签的高度约束及滚动所有权，复用原生滚动与现有容器修复 Skills 等页面不可达长内容

## Requirements

覆盖七主路由及Skills/MCP页签、列表/详情/发现区；真实输入可达长内容末尾，
不改变分栏拖动、页面保活、草稿与导航。

## Acceptance Criteria

- [ ] 先用长合成数据重现Skills已安装/发现不可滚动，记录高度与overflow链。
- [ ] wheel与PageDown/End能到达底部，不依赖脚本滚动或自动定位。
- [ ] MCP同类容器和其他路由不回归；窄窗口、双主题、页签切换与关闭模态后可滚动。
- [ ] 完整回归和门禁通过，更新SPEC、提交归档。

## Constraints

复用原生滚动、现有容器，不新建滚动引擎或凭空加入虚拟列表。
