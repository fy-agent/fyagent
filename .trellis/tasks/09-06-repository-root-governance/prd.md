# 按工具发现合同治理仓库根目录

## Goal

按实际用途分类根目录文件，集中可显式加载的工具配置，保留必要发现入口并同步所有有效引用

## Requirements

每个根文件按工具发现、发布/文档合同决定保留/移动/删除。保持唯一配置入口，
不按扩展名盲删。开发、测试、CI、编辑器和现行引用全部一致。

## Acceptance Criteria

- [ ] 根文件完整清单与用途证据；必要发现入口保留，可显式寻址配置集中。
- [ ] 移动同步root/alias/testDir/cwd，移除旧文件及兼容代理。
- [ ] scripts/CI/SPEC/有效jsonl引用更新；加入根目录与配置执行合同回归。
- [ ] dev/build/type/lint/unit/browser与完整门禁通过，SPEC/提交归档。

## Constraints

不移动工具锁/版本/包清单、项目文档/许可证或编辑器自动发现所需入口。
