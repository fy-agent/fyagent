# 订阅账号跨 Agent 复用补齐

## 目标

核对已完成的订阅登录与跨 Agent 使用能力，并补齐用户点名目标中的实际缺口。用户已授权检查、规划与实施；不重复请求常规实现确认。

## 当前范围

- 基线为最新主线 `64f4d8f6`，保留原共享工作目录与所有未提交内容。
- 确认 OpenAI / xAI 登录、凭据托管、请求转发及 Claude Code、Codex、Grok Build、OpenCode 的使用路径。
- 已有能力以现行代码与检查为准；复用现有代理、凭据、配置与恢复机制。
- 补齐 OpenCode 的订阅账号选择、模型选择、确认应用与原生配置回读。

## 验收

1. OpenAI / xAI 账号能够通过明确选择向四个目标提供订阅请求能力；Codex 保留现有保存后预览应用流程。
2. OAuth access / refresh token 不进入前端、Agent 模型配置或普通 Provider 配置；由托管认证服务在请求时解析。
3. OpenCode 与其他目标使用独立路由，不改变其他目标的账号、模型、原生认证或配置。
4. 原有未知字段、MCP、原生账号凭据和配置备份得以保留；失败回滚和并发修改不报告虚假成功。
5. 回归检查证明配置、路由、请求协议、失败处理及前端入口；真实账号与厂商调用证据独立标注。
6. 所有本次修改可审阅、提交到独立工作分支；不合并主线、不发布版本。

## 非目标

不增加第三方守护进程、容器或云中转；不转存订阅刷新令牌到其他 Agent；不替用户修改真实账号与日常 Agent 配置。
