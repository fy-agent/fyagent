# 中国市场 FDE 提示词与 MCP 预设

## Goal

调研并交付多领域 FDE 提示词及中国市场 MCP 目录，验证、更新 SPEC 并归档

## Requirements

- 在现有提示词页增加独立的 FDE 预设浏览入口，提供 30 条原创中文预设，覆盖交付基础、企业流程、产业运营、公共与专业服务、行业服务、工程运维六组。
- 每条预设包含领域输入、实施切片、交付物、验收指标和边界示例；参考 OpenAI 官方提示词、评估和工具安全建议，不冒充官方模板，不要求模型披露思维链。
- 预设可搜索、按领域筛选和预览；选用后进入当前应用的独立未保存草稿，保存后仍未启用。复用七应用库、原生保存、未保存确认与错误回读流程。
- MCP 精选目录新增 8 个官方项目配置：CloudBase、DMS、DataWorks、ACK、RDS、CloudOps、DBHub、StarRocks。提供 FDE 筛选，纳入既有国内协作工具而不复制条目。
- 新增项凭据仅进入现有密码表单与 env，不写入命令参数、搜索或描述；可限制工具范围的预设采用受限默认值，其余明确账号权限要求与风险。配置审阅与真实服务联通必须区分。
- 无后端、IPC、持久化 schema、新依赖、账户授权、生产服务调用或自动安装行为变更。

## Acceptance Criteria

- [x] 30 条预设完整、可检索、分类准确，领域内容和验收案例有实质差异。
- [x] 预览无写入；选用、保存、启用分开；重复选用不覆盖原记录；七应用隔离，dirty/cancel/failure 行为通过测试。
- [x] 新增 8 条 MCP 可生成 macOS/Windows 配置，无凭据 argv 泄漏；默认权限与官方参数一致，FDE 筛选覆盖新增和相关既有条目。
- [x] 类型、lint、受影响单元测试、浏览器交互/布局、构建和契约检查通过，未执行的验证明确记录。
- [x] 按 Trellis 完成多视角评审、更新 owning SPEC、验证任务上下文，然后归档。
