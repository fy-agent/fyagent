# 状态尺寸过渡与可感知按压

## Goal

落实父R7/R8/R9：同弹窗步骤、按钮及镜片形成可感知且不抖动的连续动作。

## Acceptance

- [x] 登录前后步骤有中间高度帧，尺寸和内容衔接，仍是同一会话且焦点/草稿不丢。
- [x] 步骤中途反向/关闭/resize/后台/减少动态效果安全收敛，敏感内容立即清理。
- [x] 快速pointer/Enter/Space/触控均有受限可感知回弹，一次业务动作，邻居无布局位移。
- [x] 页面回访镜片不从零重播；真实选择移动不中途重新起步，隐藏页无持续测量。
- [x] Chromium/WebKit真实帧及既有交互回归，导航p95≤100ms、暖态帧p95≤33.4ms目标不扩大。
- [x] 更新motion/visual/window-shell SPEC，完整prearchive后提交归档。

## Dependency

在统一目录和双主题后执行；与Theme、Dialog既有来源运动不得竞争相同属性。
