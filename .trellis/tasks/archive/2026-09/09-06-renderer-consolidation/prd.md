# 单一前端源码与工程入口收敛

## Goal

落实父R1/R2/R9：一个无代次前缀的生产前端和自动化验证体系。

## Requirements

不保留旧可启动App，不将其改名后继续维护；有意义的纯域和安全行为测试保留。
移除离线生成器/单文件预览/入口重定向及用户手册指引；真实应用HTML与后端
deep-link协议不删除。新命令按职责组织且聚合check包含实际产品质量检查。
当前后端合并的Claude CLI、可逆配置和启动行为保持。

## Acceptance

- [x] 迁移和退役清单记录职责、证据与接续测试；无未解析运行时导入和重复生产入口。
- [x] 活跃源码/配置/开发命令/SPEC无前端V2/V3分叉，历史事实和真实协议版本保留。
- [x] 旧专属依赖由可达图复核后退出，lock/许可证/审计无遗漏。
- [x] 根目录无离线HTML测试入口，正常Vite build/loopback自动化覆盖原用途。
- [x] CI分类、mise生成文档、路径/结构/资产/归档引用同步；不扩大检查豁免。
- [x] 单一类型/lint/test、原生和发布合同、浏览器/构建通过，SPEC先于提交归档更新。

## Dependency

在layout-integrity后执行；主题/动效在本任务完成的稳定目录继续。
