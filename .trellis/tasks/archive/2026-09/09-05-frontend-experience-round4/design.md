# 整合设计

## 责任边界

视觉、手势与动效留在 `src/v2/shared/ui` 和 `shared/design-system`；业务源状态继续由 feature Ports 和 Query 管理；router 仍是导航唯一权威。保留 PersistentSurface 的 hidden/inert、查询停用、草稿与秘密生命周期。动画不能创建另一份 currentView、账户状态或 native job。

## 方案

先测生产构建导航，再在当前 owner 处理导致阻塞的首次挂载、路由上下文传播、列表派生或模块竞争。不能凭直觉为所有组件加 memo、全量 eager mount、永久缓存或无界预取。随后调整材质、容器和令牌；最后叠加动效，并重测最贵的玻璃+运动组合。

动效优先使用已安装的 Motion 12.23.25 和 Radix 1.1.15。采用官方 asChild/退出生命周期整合；优先选择能保持当前焦点契约、可中断且可测试的组合。Radix CSS presence 可用于无需弹性的小型浮层；Motion 为弹簧和手势的唯一实现，不引入第二动画引擎。

毛玻璃优先现有 `@samasante/liquid-glass` 适配器和浏览器 backdrop-filter。玻璃表面只承载材质，文本不参与折射。现有库、React Bits 和额外 WebGL/截图式库的比较见研究；不因视觉演示好看而跳过 Tauri WebView、清晰度或GPU成本审查。

## 迁移与名称

`Page.tsx` 作为路由入口本身不是命名错误。只拆出已经承担独立职责的组件，例如共享 Dialog/按钮不继续堆在 `primitives.tsx`；由 owning task 决定最小文件集。按职责移动，保留内容连续性让Git识别rename，所有导入与规范引用同步。不添加长期兼容空壳，不通过重写历史制造改名记录。

`visual-language.md` 目前涵盖字阶、对话框和焦点，名字并未被证明错误。将动效、材质职责拆到明确的 focused spec 时，原文改成准确导航或缩小范围；索引、有效链接和相关归档 context 一起更新，历史叙述的原路径不当作可执行路径改写。

## 失败与降级

低性能/无滤镜浏览器仍有清晰的半透明或实色层；减少动态效果取消空间运动和回弹。触发源不存在时用中心淡入淡出，不能猜最近一个按钮。退出动画期间不允许重复提交、幽灵点击或失去焦点围栏；路由隐藏立即停止其可交互portal。

## 回滚

按性能、材质响应、动效三个提交单元推进。可分别回退视觉或motion参数，不涉及数据库迁移、原生协议或用户配置。父任务整合后再认定整体完成，不能以完成状态替代测试。
