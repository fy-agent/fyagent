#### #25 minimum correction

The current closed ID set is only `product | cli | desktop` (`src/shared/features/agents.ts:3-10`), so the acceptance condition “official homepage, actual download source and licence entry” cannot be represented for all seven products. Minimal implementation is either (a) add closed `license`/`terms` link kinds and populate every catalog entry, or (b) add a single “法律与许可” disclosure containing the relevant terms/licence URL. Keep installer artifact URLs native-owned; do not put mutable per-architecture artifact URLs into renderer catalog links. Update `reviewed_at` and add tests for seven entries, link kind uniqueness, HTTPS hosts, and no stale generic Grok/Codex links.

#### #40 minimum correction

The repository already has good endpoint separation for Ark and a pay-as-you-go Bailian preset, but it models credentials as a generic API-key field. The smallest safe change is to add closed preset metadata for `billingPlan` (`payg | coding_plan | tokenhub`), `protocol`, `region`, `keyKind`, and `allowedUse`, then make the form/connection-check select the corresponding endpoint and reject known plan/key mismatches before a request. Do not issue live model calls in this research; implementation can use parser/preset tests and an opt-in credentialed connectivity check later.

## Caveats / Not Found

- Official proprietary products generally expose terms/service-use licences rather than redistributable OSS licences. The report keeps that distinction explicit.
- TRAE terms fetched intermittently; URL is official and search result confirms the page, but exact clause text was not relied on.
- Alibaba Coding Plan exact mainland/intl hostname variants should be frozen from the plan-specific regional table at implementation time; the official FAQ confirms the `coding[-intl]` domain family and `sk-sp-` key distinction.
- Tencent is in a migration state toward TokenHub. The existing Hy3 TokenHub preset and the Hunyuan legacy-compatible endpoint are separate official surfaces; no claim is made that one can replace the other.
- No credentials were used and no model request was sent.
