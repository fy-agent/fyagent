# 全入口来源动画与异步弹窗连续性

## Goal

落实父任务 R2/R4：全部用户触发模态入口使用真实来源并完整呈现开合，重点修复用户追加的账号移除确认框，不再把共享组件接入等同于行为已经正确。

## Evidence

父 research/current-audit.md B/C：39个Dialog/包装调用中有36处来源属性；WorkBuddy信任包装及两个调用缺失。账号移除已有来源，但立即/120ms返回的预览使开场在约13–122ms内被取消。Skills菜单项卸载后返回变成中性。静态与实际生命周期需要一起治理。

## Acceptance

- [x] 账号移除的影响预览立即/开场中/之后成功或失败时，来源展开持续且正文正确交接；不等待动画才请求、不提前执行删除、不削弱确认权限。
- [x] 39调用点与所有分支形成完整清单，补齐WorkBuddy信任开关/批量动作、菜单、嵌套确认、异步结果、文件恢复和业务包装入口。
- [x] 持久来源开合均使用真实当前位置；瞬态来源打开仍有可验证的点击位置，关闭使用显式归属的有效返回点或明确中性降级，不飞向虚构控件。
- [x] pointer/Enter/Space、快速开关/反向、预览失败、取消后迟到结果、来源移除/滚走、路由隐藏、窗口缩放和减少动态效果均安全。
- [x] 取消立即撤销交互并清理秘密；旧异步响应不能污染另一个账号/新会话，不复制任何表单/账号内容制作动画。
- [x] 类型/AST检查阻止新入口静默漏接；真实生产时间/中间几何证明实际动画，不只检查origin属性或样式字符串。
- [ ] 四桌面尺寸、Chromium/WebKit和既有焦点/权限/性能回归通过，更新SPEC、完整预归档后提交归档。

## Dependency and exclusions

在scroll子任务后实施，避免控件不可达/被裁切的布局问题污染来源判断。使用现有Radix/Motion/WAAPI，不引入另一套模态/动画引擎；不新增业务删除/登录能力或真实凭证操作。
