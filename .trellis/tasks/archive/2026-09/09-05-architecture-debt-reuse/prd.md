# 架构债务审查与成熟实现复用

## 目标

对整个仓库进行可复现的架构/重复实现审查，消除已确认的通用机制重复，改善依赖方向与异步生命周期。保持现有产品行为、数据格式和安全边界，交付经过验证、更新 SPEC、已归档且工作树干净的本地提交。用户授权本任务自主调研、评审、实现至归档；不推送、不发布。

## 已确认的事实

- 基线为 `dev/laiyongjie` 的 `d628f53b`，开始时工作树干净。
- 生产渲染器是 React V2 + FeaturePorts + TanStack Query，原生宿主为 Tauri/Rust，持久层为 rusqlite。已有模块边界测试；不能用一个新框架替换所有业务。
- 全量 jscpd 固定阈值扫描覆盖 1,074 个源码文件、442,302 行（包含 Rust 内联测试），报告 79 处精确重复、3,096 重复行。它不是语义等价或债务总量证明。
- `services/tooling/versions.rs` 手写 SemVer 解析/排序；`s3_auto_sync.rs` 与 `webdav_auto_sync.rs` 复制调度与抑制机制；`database/mod.rs:84` 的更新钩子直接引用两个服务。
- `mcp/{workbuddy,qoderwork,traework}.rs` 复制 JSON 读取、备份和投影。各自路径、导入回退、协议归一化仍是不同业务规则。
- `pages/models/apply/{CodexSavePlanWorkspace,WorkBuddySavePlanWorkspace}.tsx` 复制保存编排，三个 Change Plan 工作区以 `setInterval` 轮询，慢请求可重叠，且未检查持久页面可见性。

## 边界

不改数据库 schema、Tauri command/ACL/DTO、安装器权限、凭证投影、原生事务补偿、代理协议转换或产品交互设计。保留有不同失败/补偿语义的相似代码，不把测试夹具、兼容门面或大型文件直接视为错误。审查不是承诺全仓不存在任何技术债；未安全合并的候选必须留下明确证据和处理理由。Mac 上的测试不代替 Windows 原生运行/签名/HIL 证据。
