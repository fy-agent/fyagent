# 阶段独立审查

用户最新要求：四条线继续 GPT-6 快速模式，阶段完成后由子 Agent 审查。整个更新聚焦 FDE 的特定强化与补全；实现保持简洁，界面不展示工程注释。

- 审查固定的阶段提交，不边看边改仍在写入的工作树。审查 Agent 只读代码，报告写入本任务 reviews/。
- 每个审查任务只检查本阶段的真实行为、数据和权限边界、已有功能回归、必要测试是否有效。只报可复现或有明确代码依据的问题，不提出猜测性重构和额外框架。
- 核对 FDE 用户路径是否能完成、失败是否明确、是否堆工程解释和内部标识。用户操作说明可以保留；内部注释、接线状态、revision、digest 和审计术语不进入普通产品文案。
- 优先复用已有检查，不重复跑全库。阶段发现返回所属实现线修复；root 在集成版本核对修复和最终原生路径。
- 四个线程的实际模型已回读为 gpt-6-astra、高推理，启动参数均启用 service_tier=fast。没有改全局用户配置。
