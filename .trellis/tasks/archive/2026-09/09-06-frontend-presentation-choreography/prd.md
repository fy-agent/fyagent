# 来源动效与内容连续交接

## Goal

按已核验桌面时序复用来源形变、内容交接和回程，统一空间曲线并保留按压、焦点及业务生命周期

## Requirements

落实父任务R3/R4/R5/R6/R7/R8。来源按压、外壳变形、材质互换、内容显现和返回形成
连续动作；统一流畅空间曲线而非统一所有时长。业务动作、路由和焦点规则不由
动画重定义；无效来源使用中性过渡。

## Acceptance Criteria

- [ ] 使用已核验`.32,.72,0,1`空间曲线；展开420ms，内容252ms开始168ms交接；收回360ms，内容前80ms退出、外壳16ms后返回、末90ms来源恢复。
- [ ] 点击后的前80–100ms按压反馈可辨识并和外壳起步重叠；不是先完成一套动画再调用实际动作。
- [ ] 有明确来源的桌面弹窗、确认框、popover及共享选择滑块按角色使用统一空间规则。按压仍保持克制弹性，进度/旋转不强套缓动。
- [ ] 外壳来源位置/尺寸/圆角连续，正文不被scale压扁；最终材质和内容接管前后无瞬间跳变。
- [ ] 收回移除交互并立即执行既有取消/清理；不复制输入、表单、账号详情/像素或秘密到过渡层。
- [ ] 开到一半关闭、关到一半重开、不同弹窗交接、来源移动/删除/隐藏、resize、路由隐藏及减少动态效果实时变化均有回归。
- [ ] 原有防重复提交、全新草稿会话、cancel-first、选中页签恢复和旧回调不抢新焦点全部保留。
- [ ] 同一节点只有一个变换写入者；无全局last-click推断、帧setState、第二个焦点围栏或新动画引擎。
- [ ] 父任务性能预算与V2/浏览器/完整门禁通过；更新motion-system及受影响SPEC后提交归档。

## Dependency / Out of Scope

等待`frontend-luminous-materials`完成；不擅自更改其材质预算。不搬入外部应用的
路由或数据层、不升级React/Motion主版本、不改原生启动或鉴权、不给所有变化
强加420ms等待。不把参考实现的DOM克隆/过期来源回退当成FyAgent安全契约。
