# 分支构建原生复验清单

状态：已按清单执行；实际结果见 [acceptance.md](acceptance.md)。本文件保留执行前的操作与回读要求。

运行资料根：通过 FYAGENT_TEST_HOME 指定的临时合成资料目录；完整路径仅保存在本机证据包
基线输入：合法普通日记、合法闰日日记、README.md、非法日期日记、日期同名目录，以及带中文的 Prompt 哨兵文本。所有内容为新造测试值。

| 场景                      | 原生操作                                                        | 必须回读                                                          |
| ------------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------- |
| 日记混合目录              | 打开每日记忆、读取最新/闰日                                     | 只显示2个合法文件，合法内容可读；README/非法日期/同名目录保持原样 |
| 日记搜索                  | 搜索共同检索词和单条标记，再清除                                | 共同词2条，单条词1条，清除恢复2条；无整页错误                     |
| Prompt 新建disabled       | 若启动自动导入启用，先在测试GUI停用并恢复测试哨兵，再新建库条目 | DB新增disabled；live bytes/mtime、已有backup/receipt均不变        |
| Prompt 编辑disabled       | 修改刚建条目后保存                                              | DB内容改变；live与恢复文件不变                                    |
| Prompt 导入disabled       | 从当前测试生效文件导入                                          | DB导入内容与原文件一致，保持disabled；live和恢复文件不变          |
| Prompt 再次导入已启用文件 | 将导入条目启用，再从文件导入一次                                | 新增独立disabled记录；原条目仍enabled；live与恢复文件不变         |
| Prompt 显式启用/修改/停用 | 启用一个测试条目，编辑已启用内容，再明确停用                    | 启用/编辑正确同步；明确停用仍按原语义清空；备份保留停用前内容     |
| 日记合法写入              | 编辑一个合法日记并保存                                          | 文件正确落盘，README与非法文件不受影响；恢复副本可读且等于前像    |
| 收尾                      | 退出测试构建、恢复正常安装版                                    | 真实Prompt/Memory摘要等于前置，正式应用路径/进程/数据库已恢复     |

隔离入口必须先核对环境变量、实际可执行文件、数据库打开路径。正式安装目录不替换。保存所有新构建版本/二进制摘要与结果，截图若仅在CUA历史中要如实注明。
