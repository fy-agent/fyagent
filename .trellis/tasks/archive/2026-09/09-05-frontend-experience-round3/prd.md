# 第三轮前端体验与架构整合

## 目标

保留左侧导航、AI 软件目录扫描、进入配置及分段管理的整体流程，改善实际体验中的视觉噪声、重复入口和启动未就绪画面。基线为 `84902039`，`dev/laiyongjie` 干净。

## 要求

- R1：标题、正文、辅助信息、操作栏形成一致层级；确认框紧凑但不牺牲可读性和键盘操作。
- R2：侧栏选择标记更圆润，保留原有布局、选中语义、动画和减弱动态效果支持。
- R3：安装在软件目录处理；配置页不再重复显示完整安装器。
- R4：账号登录、已有来源切换集中在账号管理；模型页保留参数编辑与明确的保存影响说明，不新增第二套认证或写入协议。
- R5：正常启动展示已渲染首屏而非空壳或路由加载画面；静默启动、再次激活和初始化错误仍可恢复。不能等待不受控的远端网络才允许打开应用。
- R6：复用已采用的 Radix、React Router、TanStack Query、Tauri 和既有业务组件，不重建 UI 框架。
