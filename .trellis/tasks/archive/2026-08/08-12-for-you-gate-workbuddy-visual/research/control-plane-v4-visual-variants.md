# v4 深色毛玻璃三种校准方向

## A｜参考忠实版（推荐）

- 基底：`#172D43`；pane：`#27465E`；strong pane：`#213F56`。
- 文字：`#F5F8FC / #D1DDE8 / #A9BDCF`。
- 选中：`#1967B5`；软选中：`#245A88`；边界：`#70BEFF`。
- 特点：最接近用户参考图的深蓝灰毛玻璃，同时保留 v3 的清晰三栏。
- 风险：需要控制环境雾光，避免重新泛白。

## B｜深石墨密度版

- 基底：`#111F2E`；pane：`#203A50`；strong pane：`#172F43`。
- 文字：`#F3F6FA / #CBD8E4 / #9FB3C5`。
- 特点：表格、MCP 参数和长列表最清晰，接近专业开发工具。
- 风险：品牌的轻盈感降低，容易重新接近传统 Windows 工具。

## C｜雾蓝平衡版

- 基底：`#203A53`；pane：`#31546E`；strong pane：`#294A63`。
- 文字：`#F7F9FC / #D7E2EC / #B5C8D8`。
- 特点：更接近参考图顶部的蓝色雾感，视觉更柔和。
- 风险：若面板透明度过高，会再次出现 v3 的白字层级问题。

## 选择原则

先用模型页分别生成 A/B/C，因为模型页同时包含列表、字段、状态和按钮，能最有效检验颜色与信息密度。专家推荐 A；B/C 只作为校准证据。确认 A 的可读性后，其余五页继承同一母版，不再各自发明颜色。
