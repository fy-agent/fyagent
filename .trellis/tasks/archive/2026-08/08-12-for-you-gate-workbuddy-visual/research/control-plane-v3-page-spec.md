# FyAgent 跨平台控制面 v3 页面规范

## 壳层

- 画布：1440 × 900。
- 风格：浅雾蓝、半透明磨玻璃、克制蓝青高光、低对比柔影。
- 标题栏：内容壳层不绘制 macOS 红黄绿按钮；Windows 版本在右上角保留最小化、最大化、关闭。macOS 由原生标题栏承载窗口控件，内容区保持相同宽度和节奏。
- 一级导航：`Agent 目录 / 模型 / Skills / MCP / 提示词 / 记忆`，单行胶囊，选中项为蓝色实心胶囊。
- 工具区：搜索、设置、用户头像；不出现 Workspace 主入口。

## 减噪规则

- 禁止口号式副标题、来源小字、卡片底部解释和“查看来源”文字链接。
- 页面内最小正文 14px；只允许状态标签使用 12px。
- 每个对象行最多两层：名称 + 一条关键状态。
- 同屏最多一个蓝色主按钮；次要操作使用玻璃描边按钮或溢出菜单。
- 详情信息默认收进右侧检查器，不在列表卡片重复。

## 页面 1：Agent 目录

- 左侧：五个受控候选列表，Qwen Code 带 `P0` 标签。
- 中间：当前候选的大图标、名称、支持能力胶囊（模型 / Skills / MCP / 提示词 / 记忆）。
- 右侧：接入状态与主动作 `开始配置`；未接入项只显示 `未配置`，不写“已验证”。
- 目的：从候选选择直接进入该 Agent 的配置，而不是展示营销说明。

## 页面 2：模型

- 页内视图：`接入源 / 路由 / 用量`。
- 左侧：接入源列表（官方登录、API、统一供应商）。
- 中间：Agent × 默认/备用模型路由表。
- 右侧：当前接入源的凭据状态、代理/故障切换开关、测试入口。
- 主动作：`添加接入源`。

## 页面 3：Skills

- 页内视图：`已安装 / 发现 / 来源 / 备份`。
- 左侧：Skill 列表与搜索。
- 中间：选中 Skill 的简洁详情和更新状态。
- 右侧：五个 Agent 的统一分配矩阵。
- 主动作：`发现 Skills`；导入 ZIP、扫描本地、恢复备份进入溢出菜单。

## 页面 4：MCP

- 页内视图：`服务 / 分配`。
- 左侧：MCP 服务列表和连接类型标记。
- 中间：选中服务的启动方式与必要参数摘要。
- 右侧：五个 Agent 的分配矩阵和健康检查入口。
- 主动作：`添加 MCP`；预设/自定义、stdio/HTTP/SSE 在新建流程中选择。

## 页面 5：提示词

- 左侧：提示词库，区分共享模板和 Agent 专属覆盖。
- 中间：大面积编辑器；标题、内容、保存为模板为主要任务。
- 右侧：Agent 分配与启用优先级。
- 主动作：`新建提示词`。
- 版本历史仅作为检查器入口，不在列表制造小字噪音。

## 页面 6：记忆

- 页内视图：`长期记忆 / 每日记录 / 身份与偏好`。
- 左侧：记忆源列表（MEMORY、Daily、USER/IDENTITY、Hermes Agent/User）。
- 中间：内容预览/编辑区。
- 右侧：Agent 可见范围、本地存储标记、启用开关和容量状态。
- 主动作：`新建今日记录`。
- 明确本地边界，不出现云同步、跨设备或已备份承诺。

## 跨平台尺寸

- 一级胶囊高度 40px，页内按钮 36–40px，图标按钮不小于 36×36px。
- Windows 窗口控件 46×40px，关闭按钮 hover 才进入危险色。
- macOS 内容区从原生安全区后开始；不为红黄绿控件额外复制一套页面布局。
- 1024–1279px 时右侧检查器变抽屉；一级导航仍保持单行，必要时只保留文字不加图标。
