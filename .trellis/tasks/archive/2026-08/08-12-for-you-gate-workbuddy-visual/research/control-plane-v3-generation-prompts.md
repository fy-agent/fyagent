# FyAgent 控制面 v3 生成提示词

## 共同基底

所有页面均引用 `fyagent-control-plane-prototype-v2.png` 或生成后的 `01-agent-catalog-v3.png`，使用以下共同约束：

> 保持 16:10 桌面应用截图、浅雾蓝磨玻璃、蓝青环境光、白色内描边、柔和阴影、胶囊按钮和青色 Y 标；左上为 Y + FyAgent；中间固定六个一级导航 Agent 目录 / 模型 / Skills / MCP / 提示词 / 记忆；右侧依次为搜索、设置、头像、Windows 最小化/最大化/关闭。删除 macOS 红黄绿控件、口号式副标题、来源链接、底部说明、伪指标和伪成功状态。正文视觉字号不小于 14px，每页只保留一个蓝色主动作。

## 01 Agent 目录

> 标题仅为 Agent 目录。左侧候选列表为 Qwen Code（P0）、WorkBuddy、QClaw、Codex、Claude Code；Qwen Code 选中。中间显示 Qwen Code 与模型 / Skills / MCP / 提示词 / 记忆五个能力胶囊和简洁节点图。右侧接入检查器只显示未配置、五步检查和开始配置。不要副标题、查看来源、批量接入、系统能力快捷卡或底部状态条。

## 02 模型

> 导航选中模型。页面页内视图为接入源 / 路由 / 用量，路由选中。左侧列出 OpenAI 官方、Anthropic 官方、通义千问、WorkBuddy API；中间是五个 Agent 的默认模型/备用模型路由表；右侧只显示未配置、凭据、代理、故障切换和测试连接。主动作添加接入源。

## 03 Skills

> 导航选中 Skills。页内视图为已安装 / 发现 / 来源 / 备份。左侧列出飞书文档、GitHub、图像生成、浏览器控制；中间显示选中 Skill 的读取/编辑/附件能力和检查更新/重新安装/卸载；右侧为五个 Agent 的统一分配开关和本地 Skill 标记。主动作发现 Skills。

## 04 MCP

> 导航选中 MCP。页内视图为服务 / 分配。左侧列出文件系统、GitHub、飞书、PostgreSQL 及 stdio/HTTP 标记；中间显示 stdio/HTTP/SSE、命令、参数、环境变量和读取文件/写入文件/列出目录权限；右侧为五个 Agent 的分配开关、未检查和检查连接。主动作添加 MCP。

## 05 提示词

> 导航选中提示词。左侧提示词库列出默认协作、代码审查、需求拆解、发布检查；中间编辑器显示“你是 FyAgent 的协作助手。先确认目标，再执行任务。重要变更需要给出验证证据。”；右侧为五个 Agent 的分配开关和基础/项目/临时优先级。主动作新建提示词。

## 06 记忆

> 导航选中记忆。页内视图为长期记忆 / 每日记录 / 身份与偏好。左侧记忆源列出 MEMORY.md、每日记录、用户偏好、Agent 身份、Hermes Memory；中间编辑器显示当前重点与工作方式；右侧为五个 Agent 的可见范围、本机存储和记忆开关。主动作新建今日记录，不出现云同步、备份或跨设备承诺。
