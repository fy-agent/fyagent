# FyAgent 控制面高保真原型评审

## Goal

在不修改产品代码的前提下，依据 2026-08-11 飞书 R4、CAP-100 评审结论、评审 Base 和原始视觉资产，生成可评审的 FyAgent 桌面控制面高保真原型图，用于决定后续前端视觉重构是否进入实施。

## Background and Decisions

- 代码基线：`main` 与 `origin/main` 均为 `5fbf862118874ba953b890bc5a579bf3b46a2658`。
- 权威评审：R4 已结束；`01 / For You Gate` 是本轮工作视觉，graphite + blue/cyan token 锁定，`05 Agent Constellation` 进入软件视觉验证。
- 发布边界：原品牌主文件 `assets/fyagent.png` 本轮不替换；概念视觉不能冒充运行时证据。
- 2026-08-12 范围修订：用户明确取消“直接做视觉落地”，改为先产出高保真原型图并评审。
- 2026-08-12 第二次范围修订：用户否定 WorkBuddy 单页和 Windows 式纯黑面板，要求 macOS 磨玻璃胶囊语言；首屏突出多 Agent 候选清单，并把模型、Skills、MCP、提示词、记忆提升为一级能力。
- 2026-08-12 第三次范围修订：视觉材质继续沿用，但桌面壳层必须同时适配 Windows/macOS；删除“比较、选择并接入……”和“查看来源”等说明性噪音，并绘制完整六页原型族。
- 2026-08-12 第四次范围修订：保留 v3 的六个一级入口、三栏布局和按钮语法；材质恢复为参考图的较深蓝灰毛玻璃，同时以当前前端数据契约重做模型、Skills、MCP、提示词、记忆的列表与详情。

## Requirements

- 原型以飞书已批准的受控 Agent 目录为产品主线，不发明未评审的候选或假运行数据。
- 视觉采用 Apple 风格的淡色磨玻璃材质：半透明框、胶囊按钮、柔和蓝青点缀、轻阴影和高可读对比；共享内容区平台中性，Windows 显示右上角窗口控件，macOS 由原生标题栏接管。
- 保留 For You Gate 的 Y 形入口符号，但弱化品牌 Hero，主视觉让位于受控 Agent 候选目录。
- 首发目录展示 Codex、Claude Code、Qwen Code、WorkBuddy、QClaw；Qwen Code 为 P0，Trae 仅为后续候选。
- Agent 目录、模型、Skills、MCP、提示词、记忆作为可直接点击的一级模块，不再藏在二级折叠里；workspace 不占首屏重点。
- 候选项只显示来源、权限与接入路径等中性说明，不写成已安装、已验证或已成功。
- 原型文案使用简洁中文；不加入不可验证的指标、客户 Logo、伪终端输出或伪成功状态。
- 页面标题不附带口号式副标题；对象行不显示“查看来源”等低频链接，来源和长说明进入详情检查器。
- Agent 目录可以表达 CAP-100 的未来受控目录；其余五页必须区分“候选 Agent”与当前可写配置的“应用”，不得把未来候选矩阵画成已实现运行态。
- 模型页以按应用的 Provider、统一供应商、当前配置、代理/故障转移和用量为真实基础，不展示尚未实现的五 Agent 全局路由矩阵。
- Skills 详情只能使用名称、描述、目录、仓库/分支、README、更新状态、时间与真实应用开关，不展示不存在的能力标签。
- MCP 详情只能使用 ID、名称、描述/标签、stdio/HTTP/SSE 配置、元数据和真实应用开关，不展示未实现的权限识别或连接健康。
- 提示词明确是按应用管理、每个应用一次只启用一条；不把共享模板、覆盖优先级、版本历史或跨 Agent 分配画成现有能力。
- 记忆明确来自 OpenClaw workspace/daily memory 与 Hermes MEMORY/USER Markdown，不展示跨 Agent 可见范围、向量检索、自动抽取或云同步。
- 本任务只产出原型图、提示词与评审依据，不修改 `src/`、`assets/fyagent.png` 或原生图标。
