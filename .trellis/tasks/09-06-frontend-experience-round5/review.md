## 同期生产性能

环境：同一production构建方式/夹具/1232×700尺寸，每CPU条件每组42次回访。
计时终点是目标页面可见后的下一帧，不包括OS输入、所有真实数据或动画结束。

| 样本       | 1x回访p50/p95 | 4x回访p50/p95 |
| ---------- | ------------- | ------------- |
| acceptance | 26.8 / 28.1ms | 36.0 / 45.9ms |
| final-2    | 26.7 / 28.7ms | 35.3 / 49.4ms |
| isolated-3 | 26.7 / 28.7ms | 35.8 / 50.0ms |

普通样本均无长任务，压力样本包含80–83ms长任务（含首访）。均在原100ms回访
预算内，也未超出规划时44.3ms基线的额外成本目标。不将不同运行噪声解释为
保证的加速倍数，更不声称所有原生设备都会达到同样延迟。

三组还分别跑了1x/4x各20次暖态模态开关及单列冷态。正常与节流组暖态帧间隔
p95均33.4ms；压力样本记录51–53ms长任务。完整周期包含测试/提交/下一帧等待，
不能拿它代替名义420+360ms动画值。静止/关闭没有残留模态与光学实例，原生轨道
句柄完成/中断都会清理；没有持续生成位移图或页面截图。

失败样本也保留：final-1因4175端口已被本轮另一组使用而未开始，不算通过；
final-3与完整仓库检查重叠时普通帧p95达到50ms，33.4ms门槛正确失败。随后隔离
复测通过，没有提高阈值。原始坏时间单位模态基线不是完整动画FPS，不能用于
声称倍数改善。日志均为/tmp/fyagent-round5-performance-acceptance.log、
final-performance-2.log、final-performance-3.log和final-performance-isolated-3.log。
