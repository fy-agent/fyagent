# 第五轮明亮玻璃与连续交互体验整合

## Goal

保留既有七条导航、目录扫描和配置流程，将偏暗的界面调整为清亮、克制的蓝灰视觉；
让按钮反馈、玻璃外壳展开、内容显现及返回来源形成连续动作，而非几个独立特效。
玻璃质感与连续性必须在可测的性能边界内实现。

## Background

基线为 `53ba8752`，分支 `dev/laiyongjie`，开始时工作树干净。第四轮已经完成
基础动效、对比度、容器响应和性能治理；本轮不重新实施或推翻这些成果。
用户明确反馈仍然偏暗、玻璃材质薄弱、按压被弹出过程遮蔽、内容交接和收回不连贯。
静态证据、已核验的桌面时序与复用选择分别见 `research/audit.md`、
`research/desktop-choreography.md`、`research/sources.md`。

## Acceptance Criteria

- [ ] 同一数据、尺寸和构建下保留前后截图；七页、对话框、输入、选中/hover、警告/错误及禁用状态一起检查。不能只调背景而保留暗色专用前景。
- [ ] 用明亮蓝灰背景与深蓝正文建立整体清亮观感，不通过整页 brightness/opacity 滤镜提亮。普通及辅助可读文本至少4.5:1，需辨识的控件/状态边界至少3:1；品牌装饰与禁用项单独报告。
- [ ] 模态区域内能辨识玻璃边缘、柔和高光与薄磨砂层次；背景分离不依靠无限增加模糊半径。材质变化到静止态无最后一帧明显换壳。
- [ ] 保留四尺寸、320px详情容器、760px断点两侧及缩放等价压力回归；无新增横向逃逸或被遮挡的操作。
- [ ] 正常时序参考：展开420ms，内容于252ms开始、168ms交接；收回360ms，前80ms内容交出、16ms后外壳开始返回、末90ms恢复来源。关键帧和实时时序均需证据，不能仅断言总时长或最终位置。
- [ ] 来源按压前80–100ms可被感知并与展开起步衔接，不用固定等待队列延后业务动作。回弹最大视觉scale仍不超过1.005，邻居布局不移动。
- [ ] 不复制表单、输入值、账号资料或截图到动效层；关闭意图立即阻断重复提交并执行既有业务取消/清理。无效来源不飞向旧位置或猜测另一控件。
- [ ] 生产导航回访p95仍≤100ms；同机同构建方式复测至少3组、每组42回访，1×/4×分别记录。普通组p95相对同期基线额外成本目标≤max(8ms, 15%)，超出先定位/简化而非修改原预算。
- [ ] 新增模态+材质组合性能样本：至少20次暖态开关及单独冷访，记录逐帧间隔、JS/layout、长任务、残留动画/节点。1×暖态帧间隔p95目标≤33.4ms，4×作压力报告；静止/关闭后没有新增持续光学帧循环。
- [ ] 遵循实际可用WebView能力；减少动态效果、减少透明度、强制颜色和无滤镜均可操作。浏览器证据不冒充真实最低系统/GPU证据。
- [ ] 所属SPEC在各任务归档前更新；最后所有本轮任务completed、上下文链接有效、工作commit可追溯、journal已记录、工作树干净。

## Out of Scope

不改导航或业务流程、原生协议、账户/凭证存储、登录权限、安装行为与启动显示策略；
不引入主题切换设置、第二套动画引擎、截图/WebGL整页玻璃或任意DOM克隆器。
不批量升级React/Motion/Radix，不改其他项目，不推送、发布或部署。
