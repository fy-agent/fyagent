## 三来源交互

### OpenClaw

- 九个固定工作区文件可搜索、选择、编辑和本地保存。
- 尚未创建的 `BOOT.md` 首次保存后在当前会话中变为已存在。
- 打开目录动作给出明确预览反馈，不伪造系统目录操作。

### 每日记录

- 可搜索、选择、编辑、保存和删除记录。
- 可创建今日记录；重复点击不会生成第二份同日记录。
- 删除使用确认步骤，打开目录动作只给出本地反馈。

### Hermes

- Agent memory 与 User profile 可独立选择、编辑和保存。
- 启用开关、字符计数、限制状态和打开 WebUI 动作均可点击。
- 所有变化只保留在当前页面内存。

## 未保存内容和单文件边界

- Prompt 条目切换、启用和新建，以及 Memory 来源和条目切换，都先检查未保存草稿。
- `pnpm build:renderer` 生成 `FyAgent-前端交互预览.html`，内联生产 CSS、JavaScript 和图片。
- `src/index.html` 与构建后的 `dist/index.html` 在 `file://` 下转入该单文件，避免浏览器阻止外部 ES module/CSS 导致白屏。
- HTTP/Tauri 启动仍使用正常 Vite 入口；预览机制没有改变后端、IPC 或持久化合同。
