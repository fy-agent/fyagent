## 视觉标尺

- 基底 #172D43；顶部和局部雾光使用 #365878、#223C55 的低透明径向场。
- shell rgba(29,55,77,.74)；pane rgba(39,70,94,.74)；strong pane rgba(33,63,86,.86)。
- 主文字 #F5F8FC；次文字 #D1DDE8；辅助文字 #A9BDCF；禁用 #7189A0。
- 主蓝 #1763AE；选中 #1967B5；焦点边 #70BEFF；启用 cyan #59C9D1。
- 正文不小于 14 像素；标题 30 像素；面板标题 20 像素。
- shell 圆角 22；pane 16；行 12；控件 10；胶囊 9999。
- 只允许一个实心蓝主动作：新建提示词。保存是描边次动作。

## 页面内容

- 固定当前应用 Codex，目标文件 AGENTS.md。
- 左栏四条原型数据：默认协作、代码审查、需求拆解、发布检查。
- 默认协作选中且启用。
- 中栏名称、描述、正文可编辑，本地保存。
- 右栏显示 Codex、目标文件、启用状态、更新时间和“一次只启用一条”。
- 禁止共享模板、优先级、版本历史和跨 Agent 分配。
