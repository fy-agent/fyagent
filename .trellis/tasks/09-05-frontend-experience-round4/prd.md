# 第四轮前端体验整合

## 目标与边界

在现有七条导航、软件目录扫描与配置流程上，改善切页即时性、容器适应性、玻璃材质可读性和交互动效。基线为 `d2d3bc47`，分支 `dev/laiyongjie`，开始审查时工作树干净。用户已授权创建任务；最终方案待确认，当前仅规划，不启动实现或声称问题已修复。

## 已确认背景

静态证据与旧截图复核集中在 `research/audit.md`；开源选择和官方依据集中在 `research/sources.md`。已确认共享弹簧只有一种快响应参数、弹窗没有来源几何契约、模态底色 alpha 为 0.98、圆角存在大量局部字面量。切页卡顿与长内容溢出的具体运行时根因仍需可重复生产构建样本，不能从文件行数断定。

## 验收

- R1：保存同一生产构建方式与确定性数据下的首访/回访性能基线和改后结果，至少30个回访样本；统计输入反馈、目标页面提交/绘制、长任务和隐藏页面读取。目标是普通样本回访 p95 不超过100ms；4倍CPU节流作为额外压力数据。若目标未达到，说明瓶颈并继续优化，不改阈值冒充通过。
- R2/R3：鼠标、键盘和触控的进入/退出、快速重复操作、来源消失、resize、隐藏页面、减少动态效果等矩阵均有回归。动效不得延迟数据写入、制造成功或破坏第三轮焦点修复。
- R4/R5/R6：主要可读文本和辅助可读文本均至少4.5:1；需辨识的控件/状态边界至少3:1。透明、渐变、选中、hover和禁用分别报告，不把孤立令牌计算当作整页合规。保留减少透明度、无滤镜和强制颜色的可用降级。
- R7：四个现有桌面测试尺寸、760px断点两侧、320px可用内容宽度/200%缩放等价压力、分栏拖拽、长中英文无空格字符串、URL、邮箱和多行错误均可操作。不以全局 overflow:hidden 截断内容掩盖溢出。
- R8：改名映射列出所有移动和理由；实际导入、样式、测试、任务 runner、构建分类器、SPEC 索引和归档上下文链接均验证，无重复实现或断链。不重写 Git 历史。
- R9：新增依赖须有许可证/版本/能力/浏览器/包体/安全审查；默认不增加 runtime 依赖。
- 每个子任务在完成实现和检查后更新所属 SPEC、提交并归档；父任务最后执行全量门禁和归档后无排除 contracts，补齐工作提交、有效引用、journal，最终没有活动任务且工作树干净。

## 不做

不改业务协议、账号/秘密存储、安装动作、Rust窗口策略或导航结构；不发布、不部署、不推送；不操作真实账号和外部软件。无需为数字刷新、光标、文本输入每次变化强加空间动画；减少动态效果时以可访问性优先。动画质量不等于所有操作都慢。
