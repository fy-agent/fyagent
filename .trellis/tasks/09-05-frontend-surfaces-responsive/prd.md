# 材质、可读性与容器响应

## 目标

让现有页面在保持布局的前提下具有清晰文字、统一圆角与可感知毛玻璃，长内容与窗口变化不溢出。父任务R4-R7的独立交付；在performance基线后实施。

## 要求与验收

- S1：同类控件/卡片/大表面/pill采用少量共享语义radius，移除无理由局部半径；允许真实圆形图标、指示点和细分隔线几何例外并有清晰归属。
- S2：普通和辅助可读文字≥4.5:1，必要可辨识控件信息≥3:1；关键文字用字重/实色/位置提高显著度，不靠夸大字号。透明背景测最终合成对比。
- S3：模态遮罩让背景适度变暗/模糊，surface有玻璃深度但不折射文字；不增加整页截图/WebGL引擎，复用现有owner和成熟滤镜。系统减少透明度/不支持滤镜/forced-colors保持可用。
- S4：四个桌面尺寸、760px断点两侧、窄拖拽pane、200%缩放等价压力和320px可用内容宽度下，长标签/URL/邮箱/中文/错误信息不逃出容器；操作可见或可通过明确滚动到达。
- S5：不靠外层overflow:hidden裁掉文字与按钮；需要横向保真的代码编辑区是明确例外，提供自己的滚动。页面不可形成重复无效滚动区。
- S6：before/after实图、计算样式、文本和边界测量及回归齐备；SPEC更新后提交归档。

当前的0.98模态alpha和19个CSS文件的圆角分散见父研究，不是已经修复的结果。
