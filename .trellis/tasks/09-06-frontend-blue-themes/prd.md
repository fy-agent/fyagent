# 亮蓝与雾蓝双主题及原点扩散

## Goal

落实父R5/R6：保留蓝色产品气质，清亮与适度偏暗可切换，扩散无明显停顿。

## Acceptance

- [x] 右上可访问按钮，pointer/键盘均可切换，偏好持久与启动主题一致；不改布局/路由。
- [x] 七页、步骤弹窗、镜片、错误/hover等两主题正文4.5:1与关键边界3:1不降低。
- [x] 暗色比参考更深但不接近黑；亮色仍是蓝灰，不只反转颜色。
- [x] 圆形从真实触发位置扩散到所有角；快速反向/失败/resize/后台可清理，无旧回写。
- [x] 减少动态效果、forced-colors、缺少API均安全切换；无隐式网络/表单重建。
- [x] 同构建下采样准备和扩散全程含中段，无通过关动画或提升阈值掩盖卡顿。
- [x] Chromium/WebKit验证、完整门禁、更新SPEC后提交归档。

## Dependency / Scope

在renderer-consolidation之后；复用现有后端主题能力，不新增设置页面，不操作真实账号。
