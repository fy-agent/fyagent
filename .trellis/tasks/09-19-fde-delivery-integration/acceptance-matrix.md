# 集成验收用例

本轮以最终集成提交和当前 macOS 原生候选为准。已有正式安装和用户数据先记录只读指纹；测试数据放独立 FYAGENT_TEST_HOME。单元、浏览器 fixture 与原生操作分别留证。

| 路径 | 关键观察 | 通过条件 |
| --- | --- | --- |
| 旧数据迁移 | 0.4.5 schema 21 临时备份副本升级、重开、失败回滚 | 旧业务行不变，新表、约束、版本齐全，local-only sync 保留 |
| A/B 项目 | 同名客户和项目、不同资源与说明、反复切换 | 身份独立；CAS 拒绝旧提交；全局配置和另一项目不变 |
| 项目上下文 | 保存说明、外部修改、路径替换、链接、重开 | 保存后回读一致；冲突不覆盖；不逃出受管目录 |
| 项目运行材料 | 受支持 CLI 的临时配置与目录生成 | 明确采用来源；如实区分产出、启动、未验证 |
| 包库 | 预览、导入、同版重复、同版篡改、导出再预览 | 版本只读、幂等、冲突拒绝；无秘密和脚本激活 |
| 经营周报 | 绑定包，执行合成输入、缺字段、零分母、重复记录 | 指标由本机计算；故障符合规则；失败不会变绿 |
| 知识客服和经营查询 | 打开入门包和失败示例 | 内容可用、边界清楚；不声称已连接知识库或数据库 |
| 验证失效 | 检查后改变项目、资源、密钥代际，再读和导出 | 保留历史但失效；A→B→A 不恢复；项目互不串用 |
| 模型检查 | 已保存的回环模型服务、错误身份、断网、迟到响应 | 绑定对象和修订；失败和不明不绿；原始响应与密钥不入账 |
| 人工验收 | 缺人、范围、依据拒绝；外部依据标人工来源；撤销 | 不自动客户验收；仅样例不足以客户验收；历史可追溯 |
| 交接导出 | 预览、JSON、Markdown、未完成项和无负责人 | 两格式一致；无 token、私有引用和路径；版本、回退限制齐全 |
| 可靠性 | R1–R8、MCP 默认范围、之前两补丁 | 每项有修复或确切上游、实机缺口；静态与实测分开 |
| 既有功能 | 原生 8 页和新增项目页、主题、导航、脏稿、隐藏页 | 关键入口和编辑流程可用；隐藏页不串状态 |

## 收尾

必要静态、领域、架构、迁移、浏览器检查和生产构建通过后，完成原生隔离路径。仅 root 替换 /Applications/FyAgent.app，再核对版本、签名、旧业务数据和唯一可启动版本。清理本轮生成的 app 和独立可执行副本，保留同版本官方恢复源。报告保留真实失败历史，并区分外部服务、Windows、正式签名发布的证据边界。
